# DeepSeek Harness Rust v0.1.3-alpha.9

## 对话与工作台

- 上下文导航稳定显示，定位未加载的用户消息时按需补页；双向翻页和历史驻留保持有界。
- 原生“插入对话”菜单支持引用 chip、草稿恢复及成功发送清理；引用上下文随对应消息一起排队，在实际接纳时进入正确回合。
- 主会话和可续聊子代理支持发送中状态、请求去重、排队编辑、删除与插话。
- 修复 localhost 网页访问、侧栏重载及关闭交互；工作区菜单可在已安装的编辑器、终端或文件管理器中打开目录。
- PTC 命令和嵌套输出支持原生展开交互，未知退出状态明确标示。

## 运行与恢复

- 修复标准预设异步挂载的初始化竞态、并发创建、失败清理和旧实例误清理。
- 旧 Windows 会话可通过普通路径或等价的系统规范路径恢复；不同工作区仍拒绝复用。
- Responses 与 Anthropic 完成事件立即结束流等待；断流、静默连接取消和受控重试形成完整闭环。
- 保留模型返回的重放状态、签名、实际模型及 Responses 输出阶段；适配器私有重放内容不进入浏览器投影。
- 修正缓存输入重复计量，官方 Responses 路由使用稳定缓存键。
- 外部 Codex 过程包含中间消息、公开推理摘要、命令和工具结果；修复提前通知丢失、半帧读取和过程覆盖。
- Windows 普通命令采用 Job Object 管理后代；根进程完成与执行树结束分别确认。Linux 优先使用可用受管 scope，能力不足时明确退回进程组。

## 内存、配置与反馈

- 消除引用裁剪的重复全量序列化、恢复和投影深拷贝、退休投影重新常驻、输入订阅遗留及子代理等待空转。
- 长引用保存固定序列的完整快照，并提供真实读取入口；persona 前后段、模型切换通知和 Provider 兼容字段已接通正式 Host。
- Headless 使用已配置的默认模型与预设，包含原生读写工具，并保留显式环境变量覆盖。
- 反馈保存在会话日志并兼容旧记录。独立提交包可预览和重试，远端交付仅在明确配置后由用户操作触发。

## 桌面视频

UU 控制面板使用完整分辨率 H.264 视频与硬件编码，支持网页直接键鼠、输入法、人工接管及失焦释放。独立控制器接收 UU SDK 画面，模型观察使用单独的有界截图。

## 发布范围

Rust 继续使用独立的分页、会话存储和发布版本。正式包保持 `core`、`skin` 与免费模型资源隔离；免费版只有在供应商允许第三方访问且真实工具往返验证通过时提供。
