# DeepSeek Harness Rust v0.1.3-alpha.12

## Windows 命令执行

- 修复祖先目录权限更新触发子目录遍历的问题。父目录只更新自身的遍历权限，避免简单命令长时间停留在沙箱准备或清理阶段。
- 分离沙箱准备、命令运行和清理预算。命令超时从实际子进程启动后计算，已完成的命令不因权限清理耗时而被误报超时。
- 命令超时保留部分输出并回收所属进程；异常退出通过归属记录恢复沙箱资源。
- 区分启动失败、权限拒绝、命令超时和取消。同类基础设施错误跨不同参数触发提醒。

## 账号与工作台

- 保留有效验证码登录请求的重试状态，补齐官方 Flash 模型目录和动态系统提示词处理。
- 修复代码、Markdown、HTML 与 PDF 预览的阅读位置恢复，并完善模型管理和诊断证据显示。
- 系统文件夹选择器返回的路径正确传入工作区表单；确认后同步选中的工作区。取消不创建工作区，选择器错误保留在界面中。

## 升级

Windows 用户应安装 alpha.12 或更高版本。alpha.11 安装包不包含上述执行修复；安装旧版本会覆盖新核心。升级保留用户数据目录中的会话、账号凭据、设置和附件。

核心程序提供 `--build-info`，报告版本、源码提交与构建时的修改状态。打包同时校验版本和源码提交，拒绝同版本旧核心及包含未提交修改的构建。各平台产物的可用性以本发布页附件为准。
