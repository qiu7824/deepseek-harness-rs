| 平台 | 架构 | 版本 | 安装包 | 便携包 |
| --- | --- | --- | --- | --- |
| Windows | x86_64 | Core / Skin / Free | `setup.exe` | `.zip` |

Core 提供完整运行时与网页工作台；Skin 另附皮肤载荷；Free 仅包含对应平台和核心程序实际通过匿名流式访问与工具往返验证的模型。免费服务的后续可用性由供应商决定。

每个平台提供 6 个完整包，共 24 个附件，统一通过 `SHA256SUMS.txt` 校验。构建对应源码提交 `24380731cf01862106193a15baa77a5bef015671`；四个平台的构建、产品门禁、安装包与便携包检查均已通过。

## Windows Shell、终端与沙箱

- 祖先目录只更新自身的遍历权限，避免权限传播扫描大量子目录，修复简单命令和原生终端长时间停留在准备或清理阶段的问题。
- 分离沙箱准备、实际命令运行和清理预算。命令计时从子进程启动后开始，已执行完成的命令不会因清理耗时被误报超时。
- 取消、异常退出和超时回收所属进程与等待任务；普通超时保留部分输出，异常退出通过归属记录恢复沙箱资源。
- 区分启动失败、权限拒绝、命令退出、超时和用户取消；同类基础设施错误跨参数变化识别，避免无效重复执行。

## 对话、工作区与文件

- 短对话或折叠后的消息没有更多内容时隐藏“返回底部”按钮；发送后恢复跟随最新回复，保留历史阅读锚点和双向分页。
- 系统文件夹选择器正确返回目录路径并回填工作区表单；确认后同步工作区。取消不创建工作区，错误保持可见。
- 代码预览支持行号定位、自动换行及阅读位置恢复；Markdown、HTML、PDF 使用独立滚动容器，PDF 保留页码、缩放和刷新后的阅读状态。
- 通过 `present` 明确交付文件，产物按回合关联；补齐会话反馈、全局面板、侧栏及移动布局交互。

## 账号、模型与上下文

- 验证码登录在临时网络错误、HTTP 408/429/5xx 后保留有效请求并退避重试，明确拒绝、过期和取消仍正常结束。
- 官方 Flash 模型目录补齐图片输入、上下文容量和动态系统提示词能力；保留已有模型、用户显式设置和第三方路由隔离。
- 模型管理区分 API 连接与账号，支持搜索、筛选、批量显示/隐藏、独立参数与草稿保护。
- V3 系统消息与普通历史分别统计，压缩和位置更新不重复计数；区分缓存读取为零、未披露统计与账号额度。
- 保留多账号切换、稳定会话缓存键和按供应商、端点、模型、账号隔离的推理回放。

## 任务、MCP 与 UU

- 用户明确暂停目标后，模型不能自行恢复；暂停立即取消当前执行。
- 诊断记录关联会话和工具调用，区分运行故障、外部服务条件及人工控制结果，运行诊断不作为长期模型经验复用。
- MCP 更新先准备新连接，配置或工具激活失败时恢复原有可用工具，成功后再清理旧连接。
- UU 升级后重新发现合法安装位置，适配新版终端兼容路径；保留设备、账号和连接归属校验，支持网页画面、批注、重连和人工接管。系统登录、解锁和验证由用户完成。

## 升级与发布校验

- 升级保留用户数据目录中的会话、账号凭据、设置和附件。
- Windows 用户应安装 alpha.12 或更高版本；alpha.11 不包含上述执行修复，重新安装旧包会覆盖新核心。
- `--build-info` 报告版本、源码提交和构建时修改状态。打包同时核对版本与源码提交，拒绝同版本旧核心和包含未提交修改的构建。
- 发布从已通过验收且与标签提交一致的四平台产物中提取，逐文件校验后上传，并回读发布页核对附件清单及哈希。
