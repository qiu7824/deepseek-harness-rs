# 0.1.3-alpha.29

- 修复 Windows npm 启动器解析与显式相对路径执行，保留失败进程回执，避免将启动失败误报为执行成功。
- 完善执行环境探测期限、终端环境解析和权限恢复诊断，减少重复探测与无效重试。
- 增加实验性 Windows 隔离账号执行后端，并将 Git 信任范围限定为当前工作区。
- 修复任务检查器参数类型与验收条件校验，以及取消任务、会话发布恢复和协作子会话导航。
- 代码图谱支持节点拖拽、缩放平移、缩略导航、关系高亮、文件与符号切换、搜索和源码行号定位；静态关联与名称推断分别显示，局部结果明确标注。
- 移除任务验收及冗余运行环境等界面入口，保留兼容的后台记录。

## English

- Fix Windows npm launcher resolution and explicit relative executable paths; preserve failed process receipts.
- Improve environment probe deadlines, terminal resolution, permission recovery diagnostics, cancellation and child-session navigation.
- Add an experimental Windows isolated-account execution backend with workspace-scoped Git trust.
- Validate task checker schemas and acceptance selectors before contract freezing.
- Add an interactive code graph canvas with drag, zoom, minimap, relationship highlighting, search and source navigation. Inferred and partial results are explicitly identified.
- Remove redundant UI entry points while retaining compatible stored records.
