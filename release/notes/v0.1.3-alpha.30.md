# 0.1.3-alpha.30

- Windows Core 捆绑固定版本的 Node.js 与 ripgrep，并校验下载归档和安装文件身份；搜索不依赖系统 PATH 中的开发工具。
- 停止会话后保留待处理输入，但不自动启动下一轮；新的继续请求可恢复执行。
- 修正 Windows 扩展路径导致的 JavaScript 内核启动失败，并保留实际底层错误。
- 安装升级同步迁移受信任原生沙箱程序的校验值，保留原工作区范围；无关项目不受其他工作区的失效配置影响。
- 只读搜索失败保留在历史记录中，不单独阻止通过内容检查的交付；未知写入效果仍须核实。
- 任务权限或运行环境发生变化时明确提示恢复操作。使用会话「任务验收」中的「切换到当前环境」确认迁移，旧验收证据失效，任务要求与效果记录保留。

模型服务超时、外部程序缺失及项目自身的测试失败仍会正常报告。安装包不包含 Python、Git、Rust 或第三方项目依赖。
