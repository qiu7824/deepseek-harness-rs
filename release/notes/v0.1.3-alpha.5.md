# DeepSeek Harness Rust v0.1.3-alpha.5

## 修复与改进

- 自动记录工具失败、结构化模型请求错误和用户负面反馈，按项目与错误类型合并计数，保留实际来源模型。
- 已知错误在同会话、同工具与匹配目标恢复成功后自动验证；未知问题可填写修正建议并确认。已验证经验在后续请求中按相关性与预算复用，支持跨模型工具经验、搜索、开关和删除。
- 当前工具参数统一通过 schema 校验后才执行，经验不会绕过权限、文件观察与运行依赖检查；上下文页显示下一次请求的经验预览。
- 冷启动后的历史会话可直接查看经验预览；历史工具快照与当前工具目录分别标示，读取预览不启动模型请求或改变会话内容。
- 审批卡保持原版样式，补全文件路径与授权范围说明；允许、拒绝、取消、重连恢复、响应重试和精确目录记忆通过实际交互验证。
- 技能目录逐步更新、正文按需加载；已加载技能支持正文变更通知、停用撤销与冷启动状态恢复，并限制自动更新的大小和数量。
- 明确 PTC 代码模式必须依赖兼容的 Node.js；在预设激活前检测实际运行环境，依赖未就绪时提供可操作的错误提示。Rust 核心与标准会话可独立运行。
- Windows 安装器修正简体中文资源，全新安装默认使用 D 盘程序目录；缺少真实启动器、运行时或包清单时拒绝编译，安装后启动前再次检查完整性。
- 账号登录与模型刷新读取供应商目录，保留模型能力、思考档位和用户显示偏好；模型编辑与重连保留会话、历史阅读位置及草稿。
- 代码图谱自动增量索引，支持 Vue 脚本、导入别名、调用关系与源码行定位；文件产物支持预览、资源管理器定位及本地应用打开。
- 免费模型目录区分候选、检测通过与发布验证。免费版仅预置通过当前发布二进制实际工具调用验证的模型。

提供 Windows x86_64、Linux x86_64、macOS x86_64 与 macOS aarch64 的 core、skin、free 便携包和安装包，校验和见 `SHA256SUMS.txt`。免费模型验证结果随对应安装包提供。
