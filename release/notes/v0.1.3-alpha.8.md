# DeepSeek Harness Rust v0.1.3-alpha.8

## 会话与工作台

- 历史分页按页数、事件数和内容大小共同限制驻留窗口；过期的轮次位置缓存随窗口释放。
- 文件树不再启动代码索引；编辑器与图表资源按需读取，闲置完整会话最多缓存一份。
- 会话恢复后释放准备阶段的循环引用，事件快照共享日志，避免保留额外的完整历史副本。
- 翻页只执行一次必要重建；历史窗口与实时流分离，向下滚动可以继续加载较新的内容。
- 修复工作台关闭后仍显示、设置读取长期停留及无法拖动宽度的问题。
- 设置读取错误明确显示并支持重试，扩展设置与设备管理采用统一控件样式。
- 移除侧边对话与重复的侧栏子智能体页；子任务继续使用原生子代理入口。
- 对话调宽手柄仅在停留悬停、键盘聚焦或拖动时显示，拖动结束后保存宽度，双击恢复默认。
- 终端与任务空闲时降低刷新频率，页面隐藏时暂停；受控浏览器默认只在操作后更新画面。

## 工作区与运行

- 添加工作区提供高级设置，可指定独立垃圾槽位置；原生 Shell、终端与临时资源使用工作区对应位置。
- 垃圾槽保留来源目录的材料，不接管非空未知目录；清理与恢复继续遵守活动引用、固定项及版本检查。
- 新会话提供所有有效 Agent 预设，极简模式与创造模式使用可运行的 Rust 插件组合。
- UU 远程设备管理支持官方客户端发现、当前账号设备查询、绑定、解除绑定、连接与指定设备断开；缺少客户端或登录时提供明确入口。
- UU 远程桌面在官方客户端打开；模型浏览器控制继续使用独立的受控浏览器。

## 发布边界

- 正式程序仅使用随包资源，避免回退到维护者的源码目录。
- core 包不包含皮肤中心，免费模型管理仅在 free 包开放；已有用户供应商配置不被删除。
- 免费包继续要求对应二进制通过匿名推理、流式响应、工具调用与工具结果回传验证。
