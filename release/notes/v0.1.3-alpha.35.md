# DeepSeek Harness-rs v0.1.3-alpha.35

## 会话与附件

- 新会话使用 Session V4；旧格式按相邻版本迁移，保留原始数据，损坏或不兼容的记录明确报错。
- 通用文件附件采用内容寻址存储，支持会话归属校验和完整导出、导入。
- 标题编辑使用版本校验，冲突时保留编辑草稿；停止操作覆盖模型运行和会话命令。

## 执行与控制

- Headless 支持标准输入、指定会话恢复及 NDJSON 输出，最终文本不因行预算被截断。
- 子代理共享根任务的并行与驻留配额，并执行配置的回合和超时限制。
- 插件操作支持取消、持久记录和失败恢复；独立用户终端与模型沙箱权限分离。
- 原生 Computer 调用绑定目标身份、截图和控制状态；提供方安全检查通过单次人工确认，拒绝和取消不生成授权回执。
- SSH 远端执行提供独立助手、工作区授权、执行查询和取消接口。

## 客户端与发行

- Web 核心版与 Flutter 桌面客户端共用 Rust Host，覆盖 Windows、Linux、macOS Intel 和 Apple Silicon。
- Flutter 包携带完整 Host、Node、网页与插件资源；macOS Host 位于应用包的 Resources 目录。
- 平台校验和覆盖 Web 安装包、Web 便携包、Flutter 便携包和 Windows Flutter 安装器。
- macOS Flutter 应用使用临时签名，未经过 Apple 公证。

远端助手需要在目标机器上单独授权工作区。应用权限、主机密钥校验和本地沙箱策略继续生效。
