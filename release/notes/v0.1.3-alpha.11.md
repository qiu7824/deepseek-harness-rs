# DeepSeek Harness Rust v0.1.3-alpha.11

## 网页 UU 画面与人工接管

- 修复详情面板打开时，工作台按钮不能正常展开的问题；打开工作台或 UU 标签时先完成面板切换。
- 已连接的 UU 画面在隐藏后重新显示时复用桌面连接，重新建立视频消费者，不重复启动控制器。
- 视频断流清理绑定对应的控制器和视频会话，过期清理不能取消新连接、释放新消费者的输入或打断智能体操作。
- 人工接管时，用户可在网页画面中自行完成系统验证，再通过“交还智能体”继续控制；智能体不代填系统密码。

## UU 兼容与终端

- 读取已安装客户端的真实版本资源，保留 4.39.2.1561 与 4.38.3.9325 的接口布局，并通过签名数据指纹发现未知构建的位置，不按版本字符串拒绝加载。
- 兼容新旧终端会话列表，支持自定义及分片到达的 Shell 提示符。
- 库存查询失败不再掩盖交互连接中的系统验证提示；终端握手成功后才登记后台任务。
- 启动失败、库存诊断和清理结果分别保留；失败记录不会耗尽正常连接额度，旧记录与后台清理不会打断新连接。

## 画面批注、账号与会话

- 浏览器和 UU 批注按会话隔离，提交当时的画面、文字及归一化坐标，形成带持久图片附件的用户消息；提交失败保留草稿。
- 同一登录方式支持保存多个账号、快速切换和移除；账号身份区分工作区与用户，迁移保留模型目录与显示偏好。
- Responses API 与账号服务分别处理缓存参数，保留稳定会话缓存键及账号隔离的加密推理回放；明确区分缓存统计缺失与缓存读数为零。
- V3 压缩保留系统指令前缀，完成的思考默认折叠，等待状态完整显示；缺失模型目录不再误标为用户隐藏。

## 中文文档与发布包

- 仓库首页 `README.md` 默认使用中文，`README.zh.md` 保留兼容入口，完整英文位于 `README.en.md`。
- 发布包同时附带中英文说明、升级与存储说明，以及 UU 控制和验证边界文档。
- `core` 提供完整运行时与网页工作台，`skin` 另附皮肤载荷；`free` 仅包含该平台、该构建实际通过匿名访问与工具调用验证的模型。

## 验证边界

UU 桌面连接、真实截图、视频传输、重连与所有者隔离已通过实测；锁屏状态下的真实 Host/ConPTY 验证能够报告系统身份验证要求，且不会产生虚假的完成通知。系统密码由用户在人工控制界面中处理；画面就绪不等于系统已完成验证。

账号服务的已有实测样本明确返回缓存读取为零，稳定缓存键与统计修复不构成高命中率保证。正式会话、附件、缓存、设置和账号凭据保留在用户数据目录，升级包不包含这些个人数据。
