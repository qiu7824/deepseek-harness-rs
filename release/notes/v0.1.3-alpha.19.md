# DeepSeek Harness Rust v0.1.3-alpha.19

- 新增工作区项目任务面板，以一份 Markdown 文件管理状态、反馈和 P0–P3 优先级，支持 AI 工具读写及并发修改检查。
- 新增本地 Agent 记忆来源识别、预览导入、规则分类和可选自动同步，保留手动修改并过滤常见敏感凭据。
- 新增小菜单设置，控制轨迹、产物、代码图谱和上下文入口。
- 统一设置页内容宽度，修复子智能体管理在窄屏下的布局。
- 保留 HTTP 请求底层错误链，复用有界连接池，提供 Codex 网络诊断；Windows 支持系统静态代理作为未显式配置时的后备。
- 包含图片生成与编辑、可选任务模型分工、Devin 订阅连接、账号栏及滚动修复，以及按安装类型选择的下载更新流程。

操作说明见 [项目任务与记忆导入](https://github.com/qiu7824/deepseek-harness-rs/blob/v0.1.3-alpha.19/docs/project-tasks-and-memory-import.zh.md) 和 [图片生成与任务模型](https://github.com/qiu7824/deepseek-harness-rs/blob/v0.1.3-alpha.19/docs/image-generation-and-task-models.zh.md)。
