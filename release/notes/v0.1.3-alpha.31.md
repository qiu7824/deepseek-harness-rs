# DeepSeek Harness-rs v0.1.3-alpha.31

## 模型回复

- 正常流式回复不再受累计 8 MiB 数据量或累计 100,000 个事件的本地截断限制。
- SSE 解析对尚未完成的单个事件保留 32 MiB 缓冲保护；空闲超时、无进展超时和取消操作继续有效。
- DeepSeek、OpenAI 兼容、Responses、Anthropic 与 Devin 的接收链路按事件或协议帧处理容量边界。

## 附件与内存

- 图片默认不设本地编码字节限制，普通文件不另设 16 MiB 单文件或 64 MiB 批次限制；HTTP 上传请求总上限仍为 300 MiB。
- 文件校验与保存采用固定大小缓冲区，避免同时保留整批解码副本。
- 上传请求传递使用所有权转移，完成后释放大缓冲区；明确失败的附件请求不再作为重试内容常驻。

## 历史对话与升级

- Windows Core 安装包沿用原安装目录与用户数据目录，保留历史对话、模型配置和工作区。
- 更新后可以在原历史对话继续交流；已失败的回合不会自动重新执行。
- 此版本不改变会话存储格式。
