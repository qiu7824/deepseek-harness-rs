# DeepSeek Harness Rust v0.1.3-alpha.6

## 界面与侧栏

- 侧栏工作台支持应用内全屏，退出后恢复普通宽度并保留编辑内容。
- 拖动宽度在松手后保存到 Host 设置，跨会话和页面重载沿用；取消拖动、进入手机布局或全屏不会覆盖桌面宽度。
- 设置中的插件页面提供侧栏声明式设置，支持宽度记忆、默认全屏、文件、Git、网页和终端入口，以及 HTTP/HTTPS 链接打开方式。
- 外观恢复到通用设置，删除 Bing 壁纸及内容字号控制，保留皮肤功能。
- 手机布局支持设置横向导航、侧栏遮罩关闭、详情面板及工作台文件树抽屉，改善模型和记忆表单的可操作性。
- 设置浮层独立于侧栏动画，窗口在桌面与手机宽度之间切换时保留编辑状态与控件可点击性。
- 子任务调用显示可展开活动卡、最近公开进度与完成、失败、中止状态，可打开确切的子会话；技能正文保留按需加载与展开查看。

## 子任务运行

- 同进程子任务保留实际父任务归属，父回合先结束时仍可收到子任务结果。
- 结果投递完成前保留父任务生命周期，消费后释放空闲运行实例；显式中止子任务时返回中止状态，删除归档任务时收拢后代执行。

## 能力边界

内置侧栏设置使用字段声明生成控件并持久化。上游第三方页签和文件查看器注册协议、多工作台布局及完整终端仿真尚未接通，详细范围见 `docs/sidebar-capabilities.md`。

网页预览仍使用 iframe；Computer Use 外部命令适配器尚不包含浏览器执行器与截图反馈循环。WebView、模型工具及 UU 远程 CLI 的接入方式见 `docs/browser-control-and-model-tools.zh.md`。

## 下载

提供 Windows x86_64、Linux x86_64、macOS x86_64 与 macOS aarch64 的 core、skin、free 便携包和安装包，校验和见 `SHA256SUMS.txt`。免费版模型以对应发布二进制的实际验证结果为准。
