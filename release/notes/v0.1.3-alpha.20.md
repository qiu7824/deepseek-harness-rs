# DeepSeek Harness Rust v0.1.3-alpha.20

Windows 安装包和便携包随附 `dsh-desktop.exe` 原生阅读客户端；开始菜单提供 Desktop (Preview) 入口。客户端打开后连接本机 Host，必要时启动随附 Host，退出时仅回收自己启动的进程树。

- 支持真实会话分组、搜索、历史阅读、主题切换、复制，以及思考和工具详情展开。
- 支持 Markdown、表格、代码和工作区图片；布局适配窗口尺寸与 DPI，文字和图片缓存设有上限。
- 反馈入口采用带文字提示和无障碍名称的图标按钮，避免占用过多会话工具栏宽度。
- ZSUI 增加响应式 Surface 与原生子控件布局支持，完善主题色与覆盖层分支。
- 更新临时资源生命周期设计文档；文档中的目标保留规则不代表宿主清理行为已全部实现。

原生阅读客户端属于预览功能：新会话、模型、设置、发送和代码图谱入口仍打开网页版，原生输入与实时发送尚未提供。Windows 混合字体在部分字重下的回退差异仍待修复。

Windows、Linux、Intel Mac 和 Apple Silicon Mac 的 Core、Skin 版本提供安装包与便携包；Free 版本仅在当前二进制的免费模型链路验收通过时提供。原生阅读客户端目前仅随附 Windows 包。

所有发布附件提供 SHA-256 校验和。
