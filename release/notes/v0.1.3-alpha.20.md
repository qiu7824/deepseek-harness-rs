# DeepSeek Harness Rust v0.1.3-alpha.20

会话反馈入口采用带文字提示和无障碍名称的图标按钮，减少会话工具栏占用，并保留反馈草稿、失败重试和提交确认。

- ZSUI 增加响应式 Surface 与原生子控件布局支持，完善主题色与覆盖层分支。
- Surface 分配使用有界容量与溢出检查；离屏图片裁剪不会因极端坐标发生整数溢出。
- 更新临时资源生命周期设计文档；文档中的目标保留规则不代表宿主清理行为已全部实现。

原生阅读客户端仍处于开发阶段，不包含在安装包或便携包中。Windows 混合字体在部分字重下的回退差异仍待修复。

Windows、Linux、Intel Mac 和 Apple Silicon Mac 的 Core、Skin 版本提供安装包与便携包；Free 版本仅在当前二进制的免费模型链路验收通过时提供。

所有发布附件提供 SHA-256 校验和。
