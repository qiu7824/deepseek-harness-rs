# DeepSeek Harness Rust v0.1.3-alpha.7

## 任务交互与权限

- 引导输入在下一次模型请求前生效，运行中的待办修改会进入执行上下文；排队消息继续可见。
- 流式输出时向上滚动会停止自动跟随，查看历史不会被新内容拉回底部。
- 已有序号的行按 Ctrl+Enter 自动续号；普通文本保留发送与引导快捷键。
- 修复 Windows 普通路径与扩展路径被判为不同工作区、授权锁异常退出后的恢复，以及 Shell 超时、错误输出和非零退出状态。
- Node 可从运行目录、PATH 或 Windows 安装记录发现；普通会话、插件、代码图谱和原生终端不要求 Node。

## 产物与垃圾槽

- “轨迹”右侧提供产物列表，支持变更查看、预览、本地打开、重命名、移入垃圾槽与恢复。
- 对话内的产物入口使用当前连接状态，修复完成输出后入口崩溃的问题。
- 临时执行位置、构建缓存、长工具输出、引用保护和恢复队列统一管理。
- 受管执行副本保全项目输入；单文件交付核对目标版本，保留冲突候选。

## 插件与工作台

- 全局插件支持启停，依赖按顺序卸载和恢复；修复回答反馈与生成式 Remote 请求的解包。
- 第三方页签与文件查看器注册、声明式设置、右侧与底部工作台、分栏和浮窗接通。
- CodeMirror 编辑、Markdown/Mermaid、结构化数据、侧边对话、任务及子智能体视图随包提供。
- 原生 PTY 支持交互输入、Unicode、尺寸同步、信号和退出状态；Git 工作台支持仓库与有效 worktree、历史、差异和常用变更操作。
- 修复布局保存时因对象键顺序误报失败，以及未保存文件草稿的版本冲突保护。

## 模型与账户

- Ultra 执行模式与推理参数分离，根据模型能力选择合法档位，并约束子任务并发、次数、深度与时间。
- Codex 账户面板提供同账户用量查询、Token 活动和已有重置卡操作；未知结果复用原幂等键核对。
- 账户桥接使用独立的官方 CLI 运行目录，不复用其他客户端的登录状态；模型侧用量工具保持只读。

## 浏览器与发布

- 侧栏和模型共用原生受控浏览器，可导航、截图、点击、输入、滚动和关闭；异常退出会释放会话。
- Windows 兼容层下保持 Edge 启动进程归属，避免误报浏览器退出和遗留后台进程。
- 流式响应兼容空的工具调用列表和心跳集合，协议错误保留具体原因。
- 外部适配器保留远程控制接入协议，具体远程服务仍需提供可用控制端。
- 浏览器净化依赖更新，随包提供锁定的构建依赖、资源摘要和许可证。
- 免费版仅包含对应发布二进制验证通过的免费模型。
