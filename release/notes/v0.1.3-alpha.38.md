# 0.1.3-alpha.38

## 文件访问与附件

- 宿主文件工具按会话身份隔离应用私有目录和受管临时资源；凭据提供者的实际文件路径独立保护，支持自定义配置目录和数据目录。
- `read`、`read_image`、`glob`、`grep`、编辑器查看、代码索引、Office 渲染和产物提交共用读取边界。路径解析与实际读取均核对规范路径；递归搜索在启动前检查受保护子目录。
- 当前会话正式接收的附件按精确文件授予读取权限；工具参数和元数据中的附件标识不能获得其他会话的附件访问权。
- 按附件 ID 读取图片时提供当前会话独立的临时副本路径，供脚本使用；共享附件对象保持不可变。
- 原生执行的受管临时目录授权限定到当前会话资源，避免授权整个共享临时资源目录。
- 旧权限按沙箱账户完成首次迁移；后续核对目录身份和授权子树，新增文件继承隔离规则。
- 代码执行在沙箱启动确认后开始计算程序预算；首次权限迁移有独立启动上限，取消可中断启动或执行。
- Git 执行副本直接复制当前工作区内容，不运行仓库定义的检出转换或文件系统监控程序。

## 执行流程

- 移除任务契约、任务验收工具与接口、完成门禁、自动验收续接、验收状态卡和契约状态上下文。普通工具执行、目标、计划、后台作业及定时任务保持独立运行。
- 技能版本由用户手动创建、启用、撤回和恢复，不依赖任务样本或验收数据库，也不显示自动验证结论。
- Office 输入的 ZIP/XML 结构与活动内容检查由独立模块执行。

## 会话恢复与界面

- 崩溃后的会话修复先关闭未完成压缩，再结束对应步骤和回合；手动压缩保留命令身份，重复恢复不重复补写结束事件。
- 继承历史边界终止上级会话遗留的压缩状态，避免新会话持续误报压缩正在进行。
- Web 与 Flutter 将自动状态同步显示为“运行信息更新”，重复调用检测显示为“重复调用提醒”；内容默认折叠，可展开核对原始信息。

## 发行核验

安装包的源代码提交、构建身份、文件清单和 SHA-256 记录在发行目录的 `BUILD-VERIFICATION.json`。
