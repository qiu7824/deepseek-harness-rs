# 0.1.3-alpha.38

## 文件访问与附件

- 宿主文件工具按会话身份隔离应用私有目录和受管临时资源；凭据提供者的实际文件路径独立保护，支持自定义配置目录和数据目录。
- `read`、`read_image`、`glob`、`grep`、编辑器查看、代码索引、Office 渲染和产物提交共用读取边界。路径解析与实际读取均核对规范路径；递归搜索在启动前检查受保护子目录。
- 当前会话正式接收的附件按精确文件授予读取权限；工具参数和元数据中的附件标识不能获得其他会话的附件访问权。
- 原生执行支持精确文件读取根，附件数量上限与桥接参数一致；无效根的诊断包含具体路径。
- 按附件 ID 读取图片时提供当前会话独立的临时副本路径，供脚本使用；共享附件对象保持不可变。
- 原生执行的受管临时目录授权限定到当前会话资源，避免授权整个共享临时资源目录。
- 旧权限按沙箱账户完成首次迁移；后续核对目录身份和授权子树，新增文件继承隔离规则。
- 代码执行在沙箱启动确认后开始计算程序预算；首次权限迁移有独立启动上限，取消可中断启动或执行。
- Git 执行副本直接复制当前工作区内容，不运行仓库定义的检出转换或文件系统监控程序。

## 执行流程

- 移除任务契约、任务验收工具与接口、完成门禁、自动验收续接、验收状态卡和契约状态上下文。普通工具执行、目标、计划、后台作业及定时任务保持独立运行。
- 技能版本由用户手动创建、启用、撤回和恢复，不依赖任务样本或验收数据库，也不显示自动验证结论。
- Office 输入的 ZIP/XML 结构与活动内容检查由独立模块执行。
- 自动发现的 PowerShell、Node 和 Python 排除其他产品的私有缓存运行时，首次选定的路径持久保存；缺失时报告失效，不静默切换程序。
- 文件与 Office 工具不依赖 Shell 环境指纹；执行类工具继续校验实际运行环境与权限。
- 人工审批等待不消耗工具或 Node 程序的执行预算；审批自身超时、停止和纯计算上限继续生效。同一轮同类审批超时后不重复等待。
- 相同执行环境下反复出现启动失败时停止重试；更换命令、工作目录或工具别名不能清除失败记录。
- 文档工作区不注入 Host 源码、Web 热更新或前端开发命令；默认工具列表精简，扩展工具按需发现。远端终端明确限定为远端操作。

## Office 数据与文件整理

- `office_read` 直接读取 DOCX 段落、表格和 XLSX 单元格；返回位置、原始值、单元格类型、数字格式及公式缓存标识，不执行公式或外部链接。
- `office_write` 直接生成真实 DOCX/XLSX，无需 Shell、Python 或沙箱进程。字符串按文本保存，保留电话号码、前导零和等号开头的字面值。
- 覆盖 Office 文件须经明确人工批准，并核对批准前的文件版本；取消、目标变化或发布失败不会删除原文件。结构检查不等同于内容对照或视觉检查。
- `file_manage` 支持经人工批准后重命名单个文件或移入可恢复回收区；拒绝目录递归、链接、覆盖已有目标及工作区外文件。
- 普通文本写入工具拒绝使用 Office、PDF 等二进制扩展名，避免将 HTML 改名为无法打开的文档。

## 会话恢复与界面

- 崩溃后的会话修复先关闭未完成压缩，再结束对应步骤和回合；手动压缩保留命令身份，重复恢复不重复补写结束事件。
- 继承历史边界终止上级会话遗留的压缩状态，避免新会话持续误报压缩正在进行。
- Web 与 Flutter 将自动状态同步显示为“运行信息更新”，重复调用检测显示为“重复调用提醒”；内容默认折叠，可展开核对原始信息。
- 运行上下文仅注入变化的命名分节；冷恢复重放增量链，压缩移除依赖或导入缺失链时重新建立完整基线。
- Flutter 的新会话使用侧栏当前选择的工作区，已有会话继续显示自身工作区。
- Flutter 增加 Computer Use 面板，可查看并加入模型的桌面操作会话。
- 长流式答复采用有界分段合并，并在完整消息替代已覆盖片段后释放缓存，保留首个片段时间及冷恢复边界。
- 旧安装位置的沙箱辅助程序缺失时，重新绑定当前发行包中的已验证程序，并保留选定的实现、网络策略及状态目录。
