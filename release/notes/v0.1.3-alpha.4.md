# DeepSeek Harness Rust v0.1.3-alpha.4

## 修复与改进

- Windows 安装器正确编译简体中文语言资源；全新安装默认使用 D 盘程序目录，升级保留原位置。缺少完整启动器、运行时或包清单时拒绝编译安装包。
- 账号登录、重连与模型目录刷新同步真实可用模型，修正 Codex 账号标识解析；模型能力与用户偏好分别维护，目录更新不覆盖同时保存的修改。
- 模型列表直接提供显示开关、搜索、批量操作、保存和取消。账号凭据与普通 API Key 编辑隔离，模型编辑失败不会清空会话。
- 思考档位、默认值与说明优先使用供应商元数据；准确保留不同档位的请求值，未知能力使用供应商默认。
- 会话列表暂缺当前项及网络重连时保留会话作用域、历史阅读位置和草稿，忽略过期请求返回的旧状态。
- 运行环境分别展示 Rust 核心和可选代码执行环境，实际检测 Node 路径、版本、权限模式及 TypeScript 能力。
- Rust 安装清单不再被误作 Node 包入口，用户数据目录不再生成无用的安装依赖链接；现有数据和迁移后的启动定位保持可用。
- 文件产物支持内嵌预览、源码行定位、资源管理器选中文件、复制路径以及本地应用／WPS 打开，统一显示 Windows 长路径与 UNC 路径。
- 代码图谱自动增量索引当前工作区，支持 Vue 脚本和配置中的导入别名；局部关系图可打开源码，同名歧义与名称推断明确标示。解析、查询和输出均有取消与资源预算。
- 免费模型页展示官方目录、价格证明及最近检测状态；仅允许添加通过检查的候选。免费版按实际发布验证结果预置模型，分别处理 Completions 与 Responses 协议。

## 下载

提供 Windows x86_64、Linux x86_64、macOS x86_64 与 macOS aarch64 的 core、skin、free 便携包和安装包，校验和见 `SHA256SUMS.txt`。免费模型验证结果随对应安装包提供。
