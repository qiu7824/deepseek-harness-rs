# 0.1.3-alpha.28

- 修复响应缓冲先回收后析构的顺序问题，覆盖最后一个字节克隆释放、提前结束与取消；主线程和工作线程分别处理自身的空闲回收。
- 准备缓存增加单项容量预算及加载取消清理；历史分页按窗口大小分配并移动载荷；不活跃历史窗口和计划任务锁不再无限保留。
- 真实历史副本对比中，启动私有内存由 158.37 MiB 降至 34.80 MiB，停止 RPC 后静置 30 秒由 65.88 MiB 降至 43.43 MiB；工作集未同步下降，长历史仍有临时峰值，详见内存生命周期核查。
- 保留标准鲸鱼图标，快捷方式和卸载入口显式引用同一图标；安装后刷新 Shell，发布时核验主程序、启动器及安装器的全部图标帧。
- 修复账号切换、运行环境和远端执行按钮样式，以及技能开关和高级预算布局；工具发现与插件中心各自管理控件样式。
- 运行环境视图忽略旧会话的迟到结果；检查与清理诊断缓存保留草稿和原修订号；项目目录显式读取，失败时仍可编辑，中文输入确认不会提前应用目录。
- 修正侧栏查看器注册、卸载和源码格式相关的发布回归，增加独立的设置控件与异步状态检查。

- 工具目录按名称稳定排序，避免重复追加相同运行上下文及额外压缩。
- Windows 沙箱支持私有目录内的完整 PowerShell 7 运行库，继续拒绝未授权目录访问及只读模式写入。
- 动态技能适用性检查不再抑制完整技能目录；加载、修改、停用、移除和冷启动状态保持一致。
- 补齐压缩恢复、重试、权限撤销和托管搜索事件登记，恢复已有日志时保留实际错误原因。
- 图片、任务和审批回归正确区分用户指令、运行上下文及压缩请求。

- 侧栏终端打开通过会话控制租约恢复冷会话，在工作区解析与 PTY 发布期间保护拥有者，修复与空闲回收的竞争；覆盖重启后连续八次重开和最终关闭回收。
- 终端已销毁拥有者使用弱引用识别确切实例，清理过期标记，避免内存地址复用导致新会话被误判为已销毁。

会话格式、账号凭据和权限选择保持兼容。内存数据来自固定历史样本与隔离测试，不代表所有工作负载的统一上限。
