# DeepSeek Harness Rust v0.1.3-alpha.22-r3

## 中文说明

此预发布版完善模型管理、输入提示和团队基础入口。团队面板提供成员与共享任务查看，完整的统一协作编排尚未包含在此版本中。

### 团队与任务基础

- 会话标题栏提供团队入口；未启用时可以查看开启开关和成员数量上限。
- 设置中提供团队设置，保存时检查配置版本；此版本的团队设置需要重启后生效。
- 团队任务草稿保留已有输入，不会自动发送。面板展示成员、实际活动状态、共享任务、依赖、文件范围和待投递消息。
- 修复定时任务兼容监听器的清理问题。

### 模型管理与输入体验

- 模型行使用紧凑的删除按钮，并保留确认、草稿保护和明确保存。
- 模型搜索框在长列表中保持正常高度，背景和焦点样式与应用统一。
- 输入框保持简短占位文字，点击或键盘聚焦后显示使用提示；重新聚焦会轮换提示，通用设置中可以关闭。
- 提示偏好可跨重启保存，写入失败时恢复原设置。

### 执行与兼容范围

- 保留 PowerShell 显式沙箱提权：需要说明理由，并在批准后执行；覆盖拒绝和取消路径。
- Computer Use 包含 Windows 原生操作、UI Automation、受控浏览器、持久 JavaScript 和 UU 远程会话等能力。
- Computer Use 尚未完整兼容 Codex 应用或 OpenAI computer 工具协议。逐应用持久授权、协议适配及完整的 macOS/Linux 原生桌面覆盖不在已验证范围内。
- 发布检查包含 ripgrep 搜索依赖；Linux DEB 包声明 ripgrep 与 bubblewrap 依赖。

## English release notes

Scope: this version includes the basic team entry and read-only board. The complete unified collaboration controls and orchestration are not included in these published binaries.

## Teams and workspace controls

- The conversation header always exposes Team. Disabled teams show an enable switch and member limit instead of hiding the feature.
- Settings includes a dedicated Team section. Changes persist with revision checks and report that a restart is required.
- Team task drafting preserves existing message text and does not submit automatically. The board displays named members, actual activity, shared tasks, dependencies, file scopes and pending messages.
- Fixed schedule lifecycle cleanup so both compatibility listeners can be disposed without moving a captured callback out of a reusable closure.

## Interface and input

- Model deletion uses a compact trash button in the model row, with an accessible name and tooltip. Confirmation, draft protection and explicit save remain in place.
- Model search retains its intended height in long menus and uses the application's neutral background and focus treatment.
- The message field keeps a short placeholder. Clicking or keyboard-focusing it reveals one usage tip; refocusing selects a different tip. Tips disappear on blur and can be disabled in General settings.
- Tip preferences persist across restarts, preserve other conversation settings and roll back after failed writes.

## Execution and compatibility

- Retains explicit PowerShell sandbox escalation with a required justification, approval before execution, and rejection/cancellation handling.
- Computer Use includes native Windows actions, UI Automation, controlled browser operations, persistent JavaScript and UU remote sessions. This is not full compatibility with the Codex application or the OpenAI computer tool protocol.
- Persistent per-application permission management, OpenAI computer-call protocol integration and complete macOS/Linux native desktop coverage remain outside the verified implementation. See the compatibility matrix in `docs/computer-use-compatibility.zh.md`.

- Release checks verify the ripgrep search dependency before testing model availability. Linux DEB packages declare ripgrep alongside bubblewrap.

## Packages

The release matrix builds Windows x86_64, Linux x86_64, macOS x86_64 and macOS arm64. Core and Skin include the same application changes. Free packages are produced only when current anonymous model checks pass and are bound to the exact runtime checksum. Portable archives, platform installers and SHA-256 checksums are verified before publication.
