# DeepSeek Harness Rust v0.1.3-alpha.14

## 对话性能

- 用户滚动已发生、浏览器尚未派发滚动事件时，布局更新保留实际滚动位置，避免将视图拉回旧位置。
- 对话和轨迹视图增量判断流式文本是否可见，避免每个片段重复检查全部历史文本。

## PowerShell

- 提供 `Invoke-DshNativeProbe` 捕获可选外部命令的退出码与完整诊断，兼容 Windows PowerShell 5.1 和 PowerShell 7。
- 诊断输出限制为 65,536 个字符，超出时标记 `Truncated`；调用方的错误策略和退出码保持不变。
- 常规命令继续采用严格错误处理；模块缺失、解释器选择和实际执行失败仍需分别处理。

## Devin / Windsurf

- 增加浏览器 PKCE 授权、账号隔离及服务端模型目录。
- 使用原生 Connect/Protobuf 传输文本、推理、图片、工具调用与用量；工具结果保留失败标记，签名按账号、模型、会话和端点隔离。
- 登录无需安装 Devin CLI；可选模型和额度取决于账号。需要额外分配的路由模型不在支持范围内。
- 连接步骤与验证项目见 [Devin / Windsurf 订阅连接](../../docs/devin-subscription.zh.md)。真实订阅授权与模型服务仍需实际账号验证。

## 历史导入

- 修复命令行导入含图片的历史 ZIP 时，在异步入口嵌套创建运行时导致的崩溃。
