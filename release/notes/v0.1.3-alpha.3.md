# DeepSeek Harness Rust v0.1.3-alpha.3

## 修复与改进

- 目录迁移重建受管安装链接，支持旧版安装包和已过期的安装链接；未知或被篡改的链接仍会拒绝迁移并保留原数据。
- 迁移后的新会话写入新数据目录，原数据入口在冷启动时自动定位到迁移后的目录。

- 工作区相对路径在所有平台统一拒绝 Windows 盘符、驱动器相对路径及 UNC 路径。
- 免费版打包校验真实的流式调用、工具结果、模型容量、工作区完整性和运行时校验和。

- 会话“上下文”标签位于“代码图谱”旁，保留用量字段并显示占用率与上下文组成；未知费用和推理用量保持未提供。
- 设置提供技能和 MCP 管理，支持编辑、搜索、启停、连接测试及凭据脱敏；已知错误记忆支持结构化维护和优先注入。
- 模型提供独立显示开关，推理档位优先读取目录元数据；DeepSeek 原生模型编辑与运行时配置保持一致。
- 原生账号登录支持 Copilot、Qwen、MiniMax 国际与中国、Nous、ChatGPT / Codex、xAI，包含续期、取消和退出；Claude Code 通过官方客户端为子智能体登录，Anthropic Messages 使用 API Key。
- 修复审批渲染错误，补全失败重试与重复提交防护；任务编辑支持取消、键盘提交和错误展示。
- 目录设置支持校验复制、保留原数据、失败回滚与空闲重启，运行环境目录用于代码运行。
- 免费版必须通过匿名推理、工具调用与工具结果续接，并携带最近 24 小时内的验证证据。

- 流式工具调用保留此前收到的 ID 和名称，空字符串与 null 续传字段不再清空工具身份。
- Windows 盘符根目录具有完整标题；工作区只接受完全限定的绝对路径。
- Windows 本地非终端子进程及进程树清理不再弹出控制台窗口。
- 模型发现支持 `data` 数组和 `models` 对象，识别更多名称、上下文窗口和输出容量字段。
- 从搜索结果打开会话后返回会话列表，展开所属工作区并定位会话。
- `read_image` 顶层与嵌套工具调用支持图片卡片，图片按需加载。
- Skill 选择支持忽略大小写的模糊匹配，前缀和连续匹配优先。
- 未读取文件的写入与编辑提供统一的路径诊断、错误码与原始原因。
- 模型设置刷新和连接恢复期间保留最近一次有效的有界历史窗口。
- 超长失败轮次先压缩流分片，再执行 4096 条展示事件和 8 MiB 响应预算。
- Windows 便携包从任意文件名启动时均可使用内嵌的受限令牌沙箱。
- Windows 注册 `pwsh` PTY，Linux 与 macOS 注册 `bash` PTY，终端 schema 只公开已注册类型。
- 对话只保留 `dsh-context-jump` 导航，移除冲突的 TurnNavigator。

## Rust 产品能力

保留有界双向历史分页、目标页跳转、超长对话窗口、上下文导航、默认展开的推理内容、原生启动器、动画图片和主题扩展。

Session 保持 JSONL/Zstd v0，投影缓存保持逐记录 v5。此版本不声明对 Node Session v1/v2 文件格式的导入支持。

## 下载

提供 Windows x86_64、Linux x86_64、macOS x86_64 与 macOS aarch64 的 core、skin、free 便携包和安装包。校验和见 `SHA256SUMS.txt`。
