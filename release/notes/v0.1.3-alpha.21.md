# DeepSeek Harness Rust v0.1.3-alpha.21

- PowerShell now supports Codex-style explicit sandbox escalation requests with `sandbox_permissions` and `justification`.
- Escalation is approved before the command starts, applies only to the current call, and fails closed on rejection, cancellation, timeout, or unavailable approval services.
- Sandbox denials now provide a precise retry hint instead of silently falling back to another working directory.
- Added regression coverage for escalation mode validation and justification pairing.
