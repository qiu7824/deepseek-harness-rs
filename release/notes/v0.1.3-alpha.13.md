# DeepSeek Harness Rust v0.1.3-alpha.13

## 会话与反馈

- 永久删除主会话时，先停止执行，再递归删除所属子智能体的会话记录；独立分支和工作区文件保留。失败后可从原入口重试。
- 消息赞踩先确认再记录，同向点击直接撤回；提交失败保留草稿，过期撤回不会创建新评价。
- 正负评价支持可选分类，分类参与持久化、日志恢复和版本比较；本地记录与向接收端投递保持独立。
- 修复分阶段投影时回合数据存储被提前替换，导致复制、评价和文件交付行不显示的问题。

## 文件与历史

- 输入框支持选择、粘贴和拖放普通文件，保留原始字节；同名不同内容独立保存，失败不清空草稿，历史文件卡片按准确路径打开。
- 普通文件每条消息最多 16 个，单个不超过 16 MiB，合计不超过 64 MiB；图片沿用图像通道限制。
- 交付文件行使用紧凑布局与类型图标，折叠数量按钮可以打开完整列表。
- `dsh history import` 支持官方 V0/V1/V2/V3 的 JSONL、Zstandard 日志和带图片的导出 ZIP，校验继承边界、序号引用和内容摘要，保留原件并拒绝覆盖不同内容。

## Agent Teams

- 显式启用 `agent-teams.enabled` 后，提供具名成员、fresh/fork 上下文、持久 peer 消息及共享任务板。
- 任务使用版本比较，支持领取、释放、状态更新和依赖校验；成员不能改写其他成员已领取的任务。
- 消息先入持久队列，目标记录后确认，使用稳定消息标识重试；重启后恢复团队状态，独立分支不接管原团队。
- 标题栏提供团队面板与成员会话入口。任务归属及文件范围用于协作，不是文件系统锁。

## 网络与模型

- Host 管理的 HTTP 客户端共用环境代理策略，支持 HTTP/HTTPS 代理、ALL_PROXY 后备和 NO_PROXY 绕过；localhost、回环地址和本机 CDP 保持直连。
- 公开网页读取继续验证目的地址与重定向；代理配置错误不泄露凭据，也不静默退回直连。
- Responses Lite 按模型目录声明或 `compat.useResponsesLite` 启用，支持历史内工具和指令、all-turns 推理上下文及既有账号隔离回放。
- 保留受保护祖先路径的沙箱处理及重连后的发送状态修复，避免重复准备超时和发送后必须刷新才能显示。

## 版本与发布

- 前端 manifest 总版本与 Web 包版本同步，模块摘要继续逐项校验；拒绝携带旧资源标识的新包。
- 版本、源码提交、二进制身份和发布包内容共同校验。各平台产物由对应 Windows、Linux、macOS 构建与安装门禁生成。
- Core 与 Skin 分别发布；Free 仅在当前平台和精确模型通过匿名访问及工具往返验证后发布。实际附件以发布页和 `SHA256SUMS.txt` 为准。
- 真实账号切换、服务端缓存效果及解锁后的 UU 输入需要在使用环境验证，模拟服务测试不代表这些外部条件已满足。

配置与边界见[会话、附件、团队与网络说明](https://github.com/qiu7824/deepseek-harness-rs/blob/v0.1.3-alpha.13/docs/session-files-teams-and-network.zh.md)。
