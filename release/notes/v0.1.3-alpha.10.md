# DeepSeek Harness Rust v0.1.3-alpha.10

## 模型、账户与经验

- 手动添加模型直接显示 ID 和名称；搜索不会隐藏草稿，空白及重复 ID 在保存前提示，失败保留编辑内容。
- 已由账号区域管理的提供方只显示一份模型目录，同名的独立自定义提供方保持可编辑。
- Codex 用量服务复用当前模型账号，按官方外部令牌协议同步并处理续期，区分认证、限流和服务错误。
- 运行状态与服务诊断不再要求逐条确认记忆，参数校验失败不直接归因于模型；已验证的工具恢复经验自动复用。
- 显式 `commentary` 中间回复在同一回合继续执行，连续仅返回中间更新或空响应时有界结束并报告未完成，普通最终答复保持原行为。
- 空答复与缺失工具调用有界恢复；有效正文触及输出上限时保留片段并续写，截断工具参数不执行、不重放。
- Responses 按项目及内容块合并，断流和畸形 SSE 前已接收的安全正文保留为正式消息。
- 聊天与轨迹保留同一步骤的多个消息，通用工具图片按需加载并释放，一次性子代理的产物链接可通过安全通道打开。
- 工具调用、思考、电脑控制动作以及轨迹指标支持中英文即时切换。
- 内置推理等级、权限说明、轨迹时间提示和 Cordis 检查入口使用对应语言；自定义名称及实际请求参数保留原值。
- 通用设置可选择回复提示使用图标或文字，偏好持久保存；工具参数和回复正文保留原内容。
- 子代理本地产物链接由文件查看通道处理，侧栏网页预览不会截走内部文件链接；Cordis 运行、停止和移除提示共用图标/文字偏好。

## 对话滚动

- 使用独立的双向分页滚动控制器，保持阅读锚点并在窗口边缘按需预取。
- 修复短历史页无法向下继续加载、追加新页时跳到底部以及迟到分页结果覆盖新窗口的问题。
- 实时事件缓冲同时受条数与字节预算限制，避免浏览历史期间持续累积大事件。
- 首个 token 到达后切换推理或生成状态，减少流式更新对整页渲染的影响。

## 本机桌面

- 支持可见窗口选择、明确重连及已绑定窗口的聚焦操作。
- 从网页发起控制时，可通过经过命中检测的系统标题栏激活已绑定窗口。
- 修复窗口激活尚未完成就发送输入的问题；窗口失焦、输入位置被遮挡、窗口禁用或用户接管时停止输入。
- 截图丢弃操作前的排队帧，静态窗口按需重建捕获会话，窗口缩放按有效内容区域处理。
- 滚轮定位与滚动使用同一操作，等待时间在执行前校验并支持取消。
- 按键与鼠标释放失败时保留状态以便重试，覆盖组合键、拖动和 Unicode 文本。
- 修复合法负数被参数校验误拒绝，覆盖向上和向左滚轮请求。
- 滚动支持 `scrollX`、`scrollY` 别名，缺失、类型错误或冲突的滚动量在输入前明确报错，避免忽略参数后误报成功。
- 审批明确区分超时、拒绝、取消与服务不可用，结束的请求通过新调用重新发起审批。

## 工作台与 UU 远程

- 本机与 UU 页面统一键盘、鼠标、缩放和窗口激活交互；激活期间不重放过期输入。
- 隐藏页面暂停刷新，截图请求串行执行，鼠标移动合并发送。
- 模型正在运行时保留已建立的桌面连接，结束后按真实空闲时间回收，不增加远端心跳请求。
- 人工接管时允许关闭本会话的控制连接，继续阻止智能体获取私密画面或发送输入；UU 暂停原因与进程断开分开报告。
- UU 全局急停改为 Ctrl+Alt+Esc，画面聚焦时保留普通 Esc；其他本机窗口的 Esc 不再误触远端接管。
- UU 首帧与有效远端视频布局关联，避免将渲染窗口的初始背景当作远端画面。
- UU 设备查询采用安装客户端的实际版本与账号身份；数字协助码和账号设备 ID 分别处理。
- `uu_terminal` 接入官方交互式终端协议，使用独立会话、审批、有界输出和明确的远端清理状态。
- UU 终端以强制新建且完成握手的专属连接确认输入归属，活跃期间不另开会话列表查询；连接被其他窗口接入时停止输入。批准关闭后核验 Shell 退出与远端库存，不把本地断连当作清理成功。

UU 终端与桌面控制均遵循远端登录要求；需要登录或解锁时停止输入并返回明确提示。官方 CLI 用于设备与终端管理，桌面画面和键鼠仍由独立 SDK 控制器提供。

## 发布范围

本机桌面控制不依赖 UU 账号或 Node.js。`core` 与 `skin` 保持资源隔离，免费模型包仍需通过独立的供应商访问与实际工具调用验收。
