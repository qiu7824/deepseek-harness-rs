# DeepSeek Harness Rust v0.1.3-alpha.17

- 图片生成和编辑复用已有模型连接，结果作为会话附件显示，支持放大、下载和继续编辑。
- 任务分工设置可分别选择主模型、排错、优化、看图及生图模型；辅助分析使用所选连接，主模型继续执行修改。
- 生成图片按可见区域加载，原图和编辑版本随会话保存、导出。
- 左下角分别显示已登录的提供商，未登录时继续隐藏。
- `present` 工具参数声明明确包含一至八个文件的限制。
- 工具参数校验支持并执行数值、文本长度和数组数量上限，避免带约束的工具无法注册。

配置和权限边界见 [图片生成与任务模型](../../docs/image-generation-and-task-models.zh.md)。
