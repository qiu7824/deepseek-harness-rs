# DeepSeek Harness-rs v0.1.3-alpha.32

- Windows 默认使用独立低权限账户沙箱，提供当前用户受限令牌备用模式，移除 AppContainer 执行后端。
- 设置页与 CLI 支持执行模式、网络策略和项目初始化；配置变更后重新核对任务环境及验收证据。
- 离线账户使用独立 WFP 规则，限制 IPv4/IPv6 的连接、UDP 和监听资源；运行前检查规则是否仍然有效。
- 普通宿主用户可维护沙箱辅助程序目录并只读核验网络规则；沙箱进程无法访问宿主控制接口。
- 团队状态与等待不再触发消息投递，显式 recover 保留队列恢复能力；等待参数范围进入工具 schema。
- workflow 参数错误通过可捕获的错误返回；phases 公开完整结构。
- 诊断列表支持完整有界加载，保留带分隔符的调用 ID，搜索能力错误保留结构化代码。
- glob 默认遵守忽略规则，可显式包含构建目录；仅有推理内容的输出截断提供一次有界恢复。
