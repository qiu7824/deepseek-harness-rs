# DeepSeek Harness Rust v0.1.3-alpha.15

- 历史分页提前保留两屏内容的加载余量，并按滚轮位移提前发起请求；读取窗口仍有上限，反向滚动继续取消过期分页。
- 订阅登录提供内置授权浏览器，支持页面点击、文本输入、按键和滚动。授权浏览器运行于 Host，远程访问 Harness 的用户也可操作该页面。
- 授权浏览器与智能体的浏览器会话隔离；完成、取消、过期和 Host 关闭时回收浏览器。地址显示移除授权查询参数，输入不写入智能体对话。
- 保留系统浏览器授权入口，用于供应商限制自动化浏览器等情况。真实账号权限和供应商登录策略以服务端为准。

使用步骤见 [Devin / Windsurf 订阅连接](../../docs/devin-subscription.zh.md)。
