# 0.1.3-alpha.23

修复持续对话中的 Agent 引用保留、沙箱权限准备重复工作，以及环境变化后的任务恢复阻断。

- 已退役 Agent 和 Session 按实例释放；清除目标服务对每代完整历史的强缓存，正常、失败、取消与持久化恢复路径共用清理协议。
- Windows 沙箱按工作区身份和只读/可写模式复用权限能力；启动阶段与命令预算分离，拒绝把应用执行别名当作真实运行时。
- 大日志按流读取，支持显式 GBK/GB18030、UTF-16 编码；PDF 与图片类型错误提供明确路由。
- 任务验收区分未分派与未知效果，支持保留要求和步骤的环境迁移及重新验收。
- 接通工具发现、技能版本、任务验收和运行环境界面，补齐技能版本 RPC 注册。
- 增加回合文件审阅、计划预览、子代理侧栏、WPS Office PDF 预览和统一插件中心。

大型目录首次权限准备可能较慢，后续执行复用已核验的目录能力。Office 内嵌预览支持 DOCX、XLSX、PPTX；不具备安全转换条件时使用本地 WPS 打开。会话、配置和凭据保持兼容。
