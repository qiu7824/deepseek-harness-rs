# DeepSeek Harness-rs v0.1.3-alpha.36

## 会话历史与桌面显示

- 修复 Session V4 升级后，可读取的 V3 会话从 Web 和 Flutter 列表消失的问题。浏览旧历史保留原日志字节，继续执行沿用既有迁移及备份规则。
- Flutter 打开历史消息时直接显示完整文字；仅跟随最新消息时逐步显示流式追加。停止跟随、完成或隐藏面板后，立即显示已收到的内容。
- 修复窄窗口和文字放大时行内代码裁切。右侧工具工作台支持新增、切换、关闭多个标签并保留视图；切换会话或 Host 后丢弃迟到结果。
- Web 与 Flutter 提供隐藏已归档、全部、仅已归档三种会话筛选。

## 提醒、定时任务与知识库

- 全局提醒支持延迟一次、指定时间、固定间隔、每天、每周和 Cron 六种规则，以及 IANA 时区、发送记录、保留策略、失败重试和编辑冲突保护。固定间隔最短 60 秒，周期提醒只补发最近一次错过的提醒。
- 独立定时任务页面支持单次、固定间隔、每天、每周、Cron、单任务启停、立即运行、会话跳转和运行记录；到期后将执行指令发送到原会话，保留用户或智能体创建来源。主机运行时调度，重启后处理错过的最近一次任务。
- 提醒使用 `schedule_*` 工具，执行任务使用 `scheduled_task_*`；两份持久化任务库分别保留，不自动迁移。归档前须停止活动提醒和任务，永久删除会话同时清理所属任务。
- Web 与 Flutter 新增知识库管理：创建、重命名、启停、文件上传或路径导入、文档移除、检索与删除。支持文本、Markdown、代码、HTML、Office 开放格式及 PDF 文本提取；模型通过 `knowledge_search` 检索已启用知识库。

## 输入、模型与设置

- Flutter 支持图片和复制文件作为附件粘贴，提供缩略图、预览、移除及错误提示；会话切换和并发导入保持附件归属及数量限制。Windows 的 `Ctrl+V`、`Shift+Insert`、右键粘贴使用同一流程；macOS、Linux 已实现相应原生剪贴板通道。
- 本地 Markdown 图片支持盘符、中文、空格和 file URI，并可点击放大。
- 模型菜单提供推理等级滑块，以及上下文占用、自动压缩阈值和立即压缩入口；推理等级使用当前模型实际声明的选项。
- Web 与 Flutter 提供快捷键搜索、编辑、冲突检查和恢复默认；macOS 使用 Command 映射，固定编辑键位受到保护，保存失败保留草稿。
- Flutter 插件页支持安装、卸载、操作进度、取消、恢复检查和重启提示；关闭页面不会取消已接受的 Host 操作。MCP 设置支持 stdio/HTTP、编辑、删除、搜索和测试。
- Flutter 原生时间上下文设置支持刷新间隔、时区、读取与保存冲突保护。提醒和时间上下文插件默认关闭，保存配置不会自动启用；默认刷新间隔为十分钟，保留显式 0 和自定义值。

## 账号与运行可靠性

- 退出账号前查询任务影响并确认具体账号；仅停止绑定该账号的工作，保留队列并暂停自动继续，API Key 与其他账号保持独立。暂停状态可随冷恢复保留。
- 修复回合交接、销毁清理及迟到持久化错误影响新手工回合的问题。暂停状态保存失败明确报错，不自动切换到其他账号继续执行。
- 定时执行任务仅在消息得到持久化确认后记录成功；失败不推进或结束原计划。编辑、删除、停用与投递共享提交顺序，主机关闭等待已接受操作完成。
- 自动审阅拒绝按当前审批策略转入人工决定，审阅故障单独报告；文件锁使用操作系统所有权，取消、异常和进程退出后释放。
- 修复长上下文错误识别、多字节工具输出截断、Git 差异和日志导出的字符边界问题；折叠的网页抓取卡片可直接打开 http(s) 链接。

- 皮肤发行包与皮肤中心退役，发行结构保留核心版和 Flutter 桌面客户端，界面提供浅色与深色模式。

## 发布修订（r1、r2）

- 修复回合结束后会话无法空闲回收的问题：提示词排队期间唯一一次回收检查落空，未派生子任务的会话（例如仅加载技能）会一直占用 Host。现在在回合结束后重试回收。
- Windows：Host 继承“忽略 Ctrl+C”状态启动时（例如由新进程组启动），界面终端的 Ctrl+C 无法中断前台命令，终端随之卡住。现在终端 Shell 总能收到 Ctrl+C；无窗口的 Host 自身仍忽略 Ctrl+C。
- Windows：原生沙箱中的终端每 200 毫秒重复调整控制台尺寸，画面不断重绘，模型调用 `terminal_open` 始终等不到启动提示而超时。现在只在尺寸变化时调整；沙箱终端输入改为原样转发，不再重复回显，Ctrl+C 也不再结束整个终端。
- 时间上下文：未指定 timeZone 时，系统报告的时区别名（Linux 常见的 `Etc/UTC`、macOS 的 `GMT` 等）不再被当作无效输入；插件可以加载，配置也能保存。显式填写的时区仍须使用标准名称。
- 发布门禁：修正打包回归中与当前 Windows 行为不符的检查（仅回环监听、会话写入锁、过期沙箱配置按失败关闭、原生 V4 工具结果解码）以及界面测试夹具与 Windows 输出编码，并统一源码格式。

## 完成边界

- Windows 安装后的原生界面尚未启动验收；macOS/Linux 剪贴板代码已实现，尚未在对应平台原生构建与实测。
- 完整首次引导、退出前任务影响提示、Flutter 团队任务派发／依赖／验收面板及部分技能版本管理仍未完成。真实供应商账号、语音服务、跨平台安装和自动更新分别验收。
- Windows 原生沙箱终端已将 Ctrl+C 转发至沙箱控制台，但其中的前台命令尚不响应；需要停止时请关闭该终端。
- 投递消息与任务回执属于两次持久化提交，进程在两者之间异常退出可能再次投递；回执不表示模型已完成任务。
- 内存优化及原 70,000,000 字节性能门槛延期，不作为该版本当前发布阻塞；历史未达标结果保留，未宣称性能验收通过。
