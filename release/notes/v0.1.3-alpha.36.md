# DeepSeek Harness-rs v0.1.3-alpha.36

## 会话历史与桌面显示

- 修复升级 Session V4 后，磁盘上仍可读取的 V3 会话从 Web 和 Flutter 列表消失的问题。浏览旧历史保持原日志字节，继续执行时按既有迁移规则保留旧日志。
- 历史读取和恢复减少临时事件正文复制，已发送的响应内容及时释放；大历史按完整来源校验后的窗口读取。
- Flutter 打开历史消息时直接显示完整文字；仅跟随最新消息时逐步显示流式追加，停止跟随、完成或隐藏面板后立即显示已收到的内容。
- 修复窄窗口和文字放大时行内代码裁切。右侧工具工作台支持新增、切换和关闭多个标签，并保留各标签视图；切换会话或 Host 后丢弃旧请求结果。

## 输入与设置

- Windows Flutter 支持通过 `Ctrl+V`、`Shift+Insert` 和输入框右键粘贴图片及复制的文件，提供附件缩略图、移除和错误提示；并发导入及会话切换保持附件归属。
- 本地 Markdown 图片支持盘符、中文、空格和 file URI，并可点击放大预览。
- Web 与 Flutter 提供快捷键搜索、编辑、冲突检查和恢复默认；macOS 使用 Command 映射，固定编辑键位受到保护，保存失败保留草稿。
- Web 与 Flutter 支持隐藏已归档、全部和仅已归档三种筛选。Flutter MCP 设置支持 stdio/HTTP、编辑、删除、搜索和测试，保存失败保留配置草稿。

## 提醒与账号

- Web 与 Flutter 设置页提供全局提醒管理，支持延迟一次、指定时间、固定间隔、每天、每周和 Cron 六种规则，以及时区、发送记录、失败重试和编辑冲突保护。固定间隔最短 60 秒。
- 提醒和时间上下文默认关闭；保存配置不会自动启用。Host 可恢复冷会话并投递到期提醒，周期任务只补发最近一次错过的提醒。时间上下文默认间隔为十分钟，支持显式 0 和自定义间隔。
- 退出账号前显示对应任务影响并确认具体账号；退出只停止绑定该账号的工作，保留队列并暂停自动继续，API Key 和其他账号任务保持独立。
- 账号暂停状态可在冷恢复后保留。修复完成回合到下一轮交接、销毁清理及迟到持久化错误影响新手工回合的问题；暂停持久化失败时明确报告错误，不自动激活其他账号。

## 运行可靠性与限制

- 自动审阅拒绝可按当前审批策略转入人工决定，审阅故障与拒绝分别报告；配置锁在异常退出后释放，长上下文错误识别和工具输出字符边界得到修正。
- 旧版会话内提醒保持只读，不自动迁移或继续投递，需要在全局提醒中重新创建。提醒投递与发送记录分属两次持久化提交，进程在两者之间异常退出时可能再次投递。
- macOS/Linux 原生图片剪贴板、完整首次引导、Flutter 插件安装卸载和团队任务面板仍未完成；外部账号、语音服务及各平台实际安装仍需分别验收。
- 最终组合候选的普通 Release 性能、生命周期组合回归和安装验收尚未完成。Host 全过程内存上限为 70,000,000 字节，现有已测候选仍未达到该门槛；客户端组件测试和构建通过不代表完整产品验收完成。

完整兼容边界见 [v0.1.7-rc.2 兼容评估](../../docs/upstream-v0.1.7-rc.2-evaluation.zh.md)和[桌面平台支持与验收](../../docs/desktop-platforms.zh.md)。
