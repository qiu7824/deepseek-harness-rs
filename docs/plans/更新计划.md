## 优先修复与补齐

1. **历史记录可见性**：V4 升级后保留 V3 会话列表；冷投影读取使用一致历史代次，验证原日志字节、标题、正文、重启与继续执行。
2. **Flutter 输入闭环**：Windows 图片和复制文件粘贴、缩略图、上传、移除、失败提示；跨会话与并发导入隔离。macOS/Linux 原生图片剪贴板单独实施。
3. **设置闭环**：MCP stdio/HTTP 编辑、凭据保留、错误回显及 Flutter 自动经验管理与候选预览已接入；补齐插件安装卸载和真实服务验收。
4. **提醒与后台行为**：旧提醒支持 60 秒重复；rc.2 的 Host 任务库、六种规则、全局恢复、发送记录及默认关闭仍需移植，须解决会话回收导致旧计时器停止的问题。时间上下文已接入生产 Host 和 Web 配置入口，默认关闭、默认十分钟，支持显式 0、自定义间隔与手动启停，配置保存不自动启用；原生配置入口和安装后操作仍待验收。
5. **产品一致性**：Web/Flutter 归档三态及 Flutter 快捷键搜索、侧栏键位提示已接入并通过组件回归；首次引导、账号任务/API Key 任务区分、Web 快捷键管理和 macOS 键位仍需补齐，Flutter 团队任务派发、依赖和验收面板仍未完成。
6. **交付验证**：三平台实际安装升级、原有会话保留、外部服务和完整内存负载；失败项关闭后再标记对应平台验收完成。
