## 优先修复与补齐

1. **历史记录可见性**：V4 升级后保留 V3 会话列表；冷投影读取使用一致历史代次，验证原日志字节、标题、正文、重启与继续执行。
2. **Flutter 输入闭环**：Windows 图片和复制文件粘贴、缩略图、上传、移除、失败提示；跨会话与并发导入隔离。macOS/Linux 原生图片／文件剪贴板已有代码实现，对应平台构建与实测待完成。
3. **设置闭环**：MCP stdio/HTTP 编辑、凭据保留、错误回显及 Flutter 自动经验管理与候选预览已接入；Flutter 插件安装卸载、确认、进度、取消及恢复入口已实现，真实网络安装源与服务仍待验收。
4. **提醒与后台行为**：[全局提醒](../global-reminders.zh.md)已接入 Host 任务库、六种规则、冷会话恢复、发送记录、冲突保护与默认关闭，Web 和 Flutter 均提供管理入口；普通 Release 的真实 HTTP 管理接口与重启保留已通过，真实提供方与安装版操作仍待验收。旧日志中的提醒保持只读，需要重新创建。时间上下文已接入生产 Host、Web 及 Flutter 原生配置入口，默认关闭、默认十分钟，支持显式 0、自定义间隔与手动启停，配置保存不自动启用；安装后操作仍待验收。独立定时执行任务已提供 Web/Flutter 主页面、会话角标、启停、立即运行与记录，使用 scheduled_task_* 工具和单独任务库；原 schedule_* 提醒合同不变。
5. **产品一致性**：Web/Flutter 归档三态、快捷键查看与编辑、搜索、冲突保护、macOS Command 映射和侧栏键位提示已接入，相关组件与 Web 发布资源回归通过。账号退出确认已进入未安装客户端候选，账号/API Key 任务隔离、回合交接及暂停持久化错误处理已通过组合生命周期回归；普通 Release 按构建身份与固定负载矩阵独立验收。首次引导、Flutter 团队任务派发、依赖和验收面板仍未完成。
6. **知识库**：两端已提供知识库与文档创建、导入、启停、检索及删除；模型可检索已启用知识库，真实资料和跨平台路径待验收。
7. **交付验证**：三平台实际安装升级、原有会话保留与外部服务；未实测项目保持待验收。内存优化及原 70,000,000 字节性能门槛延期，历史未达标记录保留，不作为当前发布阻塞。
