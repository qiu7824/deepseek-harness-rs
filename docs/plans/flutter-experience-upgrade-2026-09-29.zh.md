# Flutter 桌面体验升级计划

适用产品：DeepSeek Harness Desktop。核心范围预计 12—18 人日，按单人连续投入约 3—4 周安排。优先完成 Windows 桌面验收，macOS、Linux 共用组件并分别执行平台验收；跨平台实机等待时间另计。

目标：提高高频操作的可理解性和一致性，改善长对话阅读、中文排版与图标辨识度，降低长时间使用的内存增长和界面卡顿。

产品约定：侧栏聊天记录统一称“会话”；功能图标以 16×16 为主网格；中文文案集中管理，英文翻译与语言切换列为后续独立工作。应用图标延续白色圆角底框。

**范围与交付顺序**

| M2：核心交互完善 | 3—5 人日 | 通知拆分、输入与阅读、审批、焦点分区、快捷键和搜索入口 | 主流程通过真实键鼠和中文输入法验收 |

P0/P1 表示缺陷和体验优先级，M0—M4 表示实施里程碑；P0 的输入、权限和数据完整性问题优先处理。

**一、交互优化**

| 优先级 | 场景 | 目标行为 | 验收要求 |
| --- | --- | --- | --- |
| P0 | 输入与发送 | 明确区分“发送”“加入队列”“补充当前执行”和“停止当前执行”；发送中立即反馈；失败保留草稿与附件；中文组词期间 Enter 只提交候选词 | 不重复发送、不误发候选词、不丢草稿；新建与已有会话均覆盖 |
| P0 | 长对话与流式回复 | 底部自动跟随；用户上翻、选择文字时固定阅读位置；新内容显示计数入口；点击后回到底部 | 新消息、图片加载和工具状态更新均不抢滚动；历史加载不跳页 |
| P0 | 会话切换与断线 | 保存各会话草稿和阅读位置；旧请求失效；断线显示状态与重连入口；重连恢复待处理事项 | 连续切换、慢请求和重连不串会话、不重复提交审批或问答 |
| P0 | 审批与问题回答 | 请求显示操作、对象及影响；按钮明确授权范围；多题进度可见；提交中禁用重复操作 | 键盘可完成；取消、拒绝、过期与提交失败状态可辨认 |
| P1 | 侧栏与搜索 | 当前项、悬停项、未读项、运行项层级明确；搜索支持键盘选择和 Esc 返回；截断标题可查看全文 | 1000 个会话场景可操作；长标题和中文路径不挤占状态按钮 |
| P1 | 工具工作台 | 标签可切换、关闭；关闭后焦点落到相邻标签；保存文件定位、搜索词及草稿；后台任务状态可见 | 隐藏标签停止无效轮询，关闭标签释放所属资源，重新打开恢复轻量状态 |
| P1 | 窗口与后台任务 | 清楚区分“关闭窗口”“停止当前执行”和“停止后台服务”；退出影响只提示受影响的实际任务 | 关闭窗口后任务行为与文案一致；停止当前执行不终止其他会话的任务 |
| P1 | 设置及管理页面 | 模型、技能、MCP、插件、知识库、提醒和定时任务共用搜索、空状态、错误、保存状态和冲突处理 | 保存失败保稿；刷新冲突不覆盖编辑；操作结果有可定位反馈 |

会话表示聊天记录；任务表示执行工作；提醒与定时任务分别保留其语义。涉及后台运行的按钮使用具体对象名称，避免同一“关闭”同时表示隐藏界面和终止执行。

**通知与键盘交互**

根组件仅订阅主题和真正影响应用配置的状态；侧栏列表、连接状态、当前会话元数据、审批分别采用有明确归属的通知源，继续复用消息和投影通知。禁止通过增加互相转发的通知器形成重复刷新。

验收使用固定内容与窗口：后台会话状态变化、列表刷新且当前会话正文未变化时，已完成消息的 Markdown 解析次数和正文子树重建增量均为 0；当前会话状态变化仅更新必要区域。主题、字号、窗口尺寸或可见正文改变时允许正常重建。

| 操作 | 设计规则 |
| --- | --- |
| 搜索与命令入口 | 沿用 Ctrl/Cmd+K，默认搜索会话，提供页面与命令分组；执行项显示具体动作与可用状态；保留已有用户键位 |
| 分区焦点 | 侧栏、会话、工作台分别建立焦点组；F6 / Shift+F6 往返切换，记住各区最后焦点；浮层打开时焦点留在浮层 |
| 会话与标签切换 | Ctrl/Cmd+1…9 可绑定当前可见会话；Ctrl+Tab / Ctrl+Shift+Tab 在活动工具区切换标签，在会话区切换会话，提示当前作用域 |
| 停止执行 | 为“停止当前执行”提供可配置的 Ctrl/Cmd+. 默认建议，执行前检查平台保留键、用户绑定及当前状态；不占用 Esc |
| 审批 | Enter/Space 仅激活明确聚焦的按钮；审批卡出现时不自动聚焦批准按钮；Esc 只关闭可关闭浮层或返回原焦点，待审批状态保留；拒绝通过明确的拒绝操作提交 |
| 输入与终端 | 保留输入法组词、文字编辑和终端优先规则；新增快捷键纳入现有编辑器、冲突检查与平台映射 |

按钮和可点击列表动作采用手形指针，文本选择区采用文本指针，分隔条采用调整指针并支持双击恢复默认宽度。列表首次加载使用尺寸稳定的占位骨架，按钮提交使用局部进度，超过 1 秒的操作显示明确说明。

重命名与归档可先反馈待同步状态，保留原值与操作代次；服务端失败时回滚对应操作并保留重试入口，不覆盖后续修改。运行中会话的归档限制继续遵循 Host 行为，审批、删除和停止执行以服务端实际回执显示结果。

**二、UI 细节规范**

视觉方向为中性背景、清晰层级、少量蓝色强调。主操作突出，辅助操作保持安静；状态同时使用文字和图形表达。

以 `DshTokens`（ThemeExtension）提供颜色、间距、圆角及控件密度的唯一来源，`app.dart`、`DshColors` 和 Shad/Material 主题从同一组值派生。`DshTypography` 管理字体角色，`DshMotion` 管理时长与缓动，`DshBreakpoints` 管理布局断点。成功、警告、错误与信息色分别定义前景、背景和边框。

| 项目 | 规范 |
| --- | --- |
| 间距 | 使用 4、8、12、16、24、32 逻辑像素；列表、卡片与弹窗各自统一内边距 |
| 圆角 | 输入框和按钮 8；卡片和弹出菜单 12；主要弹窗 16；胶囊作为具名特殊样式；按组件用途固定 |
| 组件状态 | 默认、悬停、按下、焦点、选中、禁用、加载、错误统一定义；焦点框在深浅主题均可辨认 |
| 控件尺寸 | 桌面普通按钮高 36，主要操作 40；图标通常 16/20，点击区域至少 36；触摸模式采用至少 48 的点击区域；文字放大后高度可增长 |
| 色彩 | 将基础、表面、边框、正文、辅助文字、强调、成功、警告、错误定义为语义色；移除页面内同义硬编码色 |
| 响应式 | 最小窗口保持 720×520；900 以下收纳侧栏，1100 以下工作台采用覆盖面板；关闭覆盖面板后恢复原焦点 |
| 阅读宽度 | 常规对话以 760—920 逻辑像素为目标范围，窄窗口自适应；代码与表格允许独立横向滚动 |
| 动效 | 悬停与状态切换 120 ms，面板及标签 180 ms，主要弹窗至多 240 ms；采用统一缓动，尊重系统减少动画偏好；流式文字不逐字附加淡入动画 |
| 浮层 | Tooltip、菜单、下拉框、弹窗统一对齐与屏幕边缘避让；Esc 优先关闭最上层浮层 |

浅色辅助文字当前色值 `#81858c` 与纯白背景的计算对比度约为 3.71:1，采用候选值 `#6b7078` 时约为 4.98:1。正文及小号辅助说明至少达到 4.5:1；实际验收覆盖侧栏、卡片、悬停背景和深色主题。文字对比度采用 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)的计算方法与普通文字目标。

焦点提示在键盘导航、辅助技术及明确需要定位时可见，不干扰普通鼠标悬停。设置标签对齐、会话行截断、消息操作条、审批与问题卡、空状态及滚动条共同使用基础规范；页面内容可滚动时提供可发现的滚动提示。

迁移约束逐模块启用：新增和已迁移的业务组件使用语义颜色、字体与图标；设计层定义、数据图谱调色板及第三方组件适配允许具名例外。避免一次性全库替换造成无关页面回归。

**三、文字与阅读体验**

| 术语 | 使用范围 |
| --- | --- |
| 会话 | 侧栏聊天条目及其历史、草稿；新建、搜索、重命名、归档会话 |
| 当前执行 | 会话正在运行的回合或工作；停止按钮使用“停止当前执行”，不表示删除会话 |
| 项目任务 / 定时执行任务 / 子任务 | 分别对应项目清单、定时运行与委派执行；不合并为一个泛称 |
| 辅助模型 | 排错、优化、看图、生图、搜索等专用模型路由；配置键与协议中的 task-models 保持兼容 |
| 工作区 / 工作目录 | 工作区是登记的项目环境及所属会话范围；工作目录是当前会话实际运行的目录 |

新增 `lib/l10n/zh.dart` 作为中文文案入口，参数通过具名字段或方法插值，依次迁移外壳、对话、审批、设置及其他管理页。模型正文、用户内容、协议标识和日志原文保持各自语义，避免按中文字符全库替换。键名和参数为后续 `gen_l10n` 迁移保留稳定结构。

新增 `DshError.describe` 统一呈现操作失败原因、恢复动作和可复制的技术详情。依据结构化错误类型映射文案，详情默认折叠并处理凭据等敏感内容；保留错误码、取消及重试语义。迁移直接拼接原始异常的界面入口，并覆盖未知错误回退。

| 内容 | 默认目标 | 处理要求 |
| --- | --- | --- |
| 普通界面文字 | 14 / 22 | 列表、按钮和设置项统一，重要标签不依赖超小字号 |
| 对话正文 | 15 / 24 | 中文连续阅读优先，支持用户调整至 14—18，保持完整系统文字缩放 |
| 输入区 | 16 / 24 | 多行高度自然增长，工具栏固定在输入区底部 |
| 辅助说明 | 12—13 / 18—20 | 保持足够对比度；错误与关键任务状态采用正文尺寸 |
| 页面标题 | 22 / 30 | 避免每页独立配置标题体系 |
| 代码与日志 | 13 / 20 | 使用等宽字体，支持复制、换行开关和横向滚动 |

上述数值为字号 / 行高，单位为逻辑像素。界面文字收敛为 12/13/14/15/16/18/22/26 的角色令牌，中文说明最小 12；富文本标题与用户字号偏好允许按角色派生，统计数字使用等宽数字特性。

Windows 使用 Segoe UI 与微软雅黑回退；macOS 使用系统字体与 PingFang SC；Linux 使用可用的 Noto Sans / Noto Sans CJK SC 或系统中文回退。等宽字体按平台选择可用的 Cascadia Mono、Consolas、SF Mono、DejaVu Sans Mono，并保留通用 monospace 回退。字体放大不得通过缩小字形、强制固定行高或裁切内容适配容器。

Markdown 统一标题间距、段落间距、列表缩进、引用、表格和代码块。数学公式、Mermaid、大表格和图片保持独立布局边界；流式阶段与完成状态之间切换不改变既有段落的阅读位置。复制代码保留原始换行，复制正文不混入操作按钮文字。

| 状态 | 界面文案范式 |
| --- | --- |
| 连接中 | 正在连接本地服务… |
| 断线 | 连接已断开，正在重连；可用操作为“立即重连” |
| 执行中 | 正在执行；存在明确步骤时显示当前动作，如“正在读取文件” |
| 等待用户 | 等待你的确认；审批卡内明确待执行操作 |
| 保存失败 | 保存失败，修改内容已保留；可用操作为“重试” |
| 文件读取失败 | 无法打开文件；按错误类型提供“重新选择”“重试”或“查看详情” |
| 无搜索结果 | 没有找到匹配的会话；可用操作为“清除筛选” |
| 回合结束 | 显示“本轮回复结束”；任务完成情况按实际验收状态分别展示 |

界面错误先说明发生了什么以及下一步能做什么，完整技术错误放入可展开详情。统一全角中文标点、时间格式、路径截断和数量单位；移除面向普通用户的无解释英文状态和协议字段名。

文字缩放 100%、125%、150%、200% 与 Windows 显示缩放分别验收，重点检查输入框、模型选择器、审批按钮、侧栏计数和弹窗底部操作区。键盘导航与读屏标签按 [Flutter 无障碍指南](https://docs.flutter.dev/ui/accessibility)验证。

**四、内存与渲染优化**

内存指标分别记录 Flutter 进程、Rust Host 及相关子进程。Windows 使用 Private Bytes 与 Working Set；Dart 分配、对象保留关系、图片及原生资源单独分析。各进程 Working Set 的简单加和可能重复计算共享页，报告中保留进程明细。

| 资源 | 当前代码预算或行为 | 升级工作 |
| --- | --- | --- |
| 历史事件 | 8192 个事件、8 MiB 字节预算 | 保留分页与事件合并；核查事件、投影和渲染文本的重复保留；回看历史可继续分页读取 |
| 实时缓冲与投影 | 实时缓冲 2000 事件 / 2 MiB；投影 2 MiB | 分别记录峰值、溢出及重同步；压力下保证最终结果与审批事件完整 |
| Flutter 图片缓存 | 48 MiB、128 项 | 记录缓存、live 与 pending 三类数量；按实际显示尺寸和像素密度解码，关闭预览解除引用 |
| Markdown 图片 | 普通显示解码宽度 1600，预览 2400 | 加入解码宽高及像素总量约束，覆盖细长大图；缩略图与放大预览使用分级尺寸 |
| 文档与计划缓存 | 文档 8 MiB，计划最大保留文本预算 8 MiB | 统一淘汰策略与归属计数，检查原始字节、解码字符串、行索引等额外副本 |
| 附件放大预览 | 待发送图片预览按 2000 像素宽解码，与 Markdown 图片路径独立 | 统一按布局和 DPR 计算目标尺寸，限制解码像素总量，避免重复保留缩略图与原图解码结果 |
| PDF 预览 | 通过 Host 获取字节，`PdfViewer.data` 读取；查看器页面图片缓存上限 48 MiB | 评估受控的临时文件或授权读取句柄，减少完整字节副本；隐藏页停止渲染，关闭释放文档、页面与原生句柄 |
| 工作台标签 | Offstage 保留状态并关闭非活动动画 | 隐藏即暂停轮询；可重建预览以隐藏 2 分钟作为初始回收策略，资源压力下提前回收；只保留定位、搜索词和草稿 |
| 终端与轮询 | 终端最多 3000 行及定时读取 | 验证隐藏、关闭、切换会话后的定时器、流和回调清理；释放视图不误终止仍需运行的任务 |
| Computer Use | 已替换当前帧并淘汰旧帧缓存，隐藏时暂停轮询 | 对帧原始字节、解码图像、未完成请求和回调增加诊断；压力下只保留当前展示和必要在途帧 |

PDF 加载优化保持 Host 的会话授权、文件大小限制、取消及 Office 转 PDF 路径；客户端不能仅凭界面中的路径绕过 Host 直接读取文件。采用临时文件时明确创建、关闭、异常退出后的清理归属。隐藏预览的回收必须能够恢复位置，且不销毁未提交草稿、运行中终端任务或 Computer Use 控制会话。

这些预算控制各自的缓存或估算保留字节，不能代替进程内存测量。Flutter 图片还可能存在活动引用，单纯缩小缓存上限不足以判断内存是否已释放，见 [ImageCache API](https://api.flutter.dev/flutter/painting/ImageCache-class.html)。

优化顺序为：先定位持续增长对象，再减少大对象重复持有，然后调整缓存预算，最后优化渲染热点。使用 [DevTools Memory](https://docs.flutter.dev/tools/devtools/memory)比较同一场景前后的堆快照和保留路径；使用 Profile 定位问题，使用普通 Release 测量用户实际使用的进程占用。GC 和操作系统可能保留已分配空间，回收验收同时检查活动对象与重复循环后的平台期。

渲染方面保留已有局部通知与 Markdown 缓存，先测量主题、侧栏、输入区和消息列表的重建范围。热点成立时将变化限制在活动消息和状态行；已完成 Markdown 块复用解析结果，未完成尾部有界刷新，结束后校正完整结构。长列表继续按可视范围构建，任何布局优化必须通过历史锚点、文本选择和大字号回归。方法依据 [Flutter 性能实践](https://docs.flutter.dev/perf/best-practices)。

**专项负载与拟定指标**

M0 固定一台验收机，记录 CPU、内存、GPU、系统、驱动、Flutter SDK、窗口尺寸、显示缩放与构建提交；每个场景至少重复 3 次。全部数值为工程目标，结果报告填写实际测量值。

日常基线场景包含冷启动后空闲、200 条消息、10 张固定尺寸图片、50 页 PDF、3000 行终端输出、Computer Use 连续运行 5 分钟，以及 20 个不同会话往返切换。专项压力场景另列如下，两类结果保持各自固定负载，不混用对比。正式报告保存为 `docs/memory/flutter-baseline.md`，原始采样与性能快照保存在操作目录。

| 场景 | 固定负载 | 验收目标 |
| --- | --- | --- |
| 常规交互 | 输入、搜索、菜单与侧栏切换 | 输入事件到界面反馈 P95 ≤50 ms；不含网络、模型推理和文件读取等待 |
| 缓存会话切换 | 两个已加载会话往返 100 次 | P95 ≤200 ms；无内容闪错、草稿丢失和累积订阅 |
| 长历史 | 单会话累计 10000 条消息、含长代码与表格，反复分页 | 活动窗口预算受控，历史仍可访问，选区和锚点稳定 |
| 流式压力 | 固定模拟服务每秒 30 次 delta，持续 10 分钟，混合工具状态 | 60 Hz 下 UI、Raster 帧耗时各自 P95 ≤16.7 ms；任一线程超帧预算的帧比例 ≤1% |
| 图片与 PDF | 连续打开 20 张 4K 图片及 200 页测试 PDF，再关闭预览 | 重型对象引用释放；同负载 Release 峰值相对 M0 以降低 20% 为专项目标 |
| 生命周期循环 | 前 5 轮预热；每轮执行打开、切换、关闭同一组面板，共 20 轮 | 以第 5 轮静置 60 秒值 B 为基准；第 20 轮同等静置值不超过 B + max(0.10×B, 32 MiB)；不出现随轮次线性增长的活动对象 |
| 资源归属 | 关闭单个标签、切换会话、断线重连及卸载页面 | 已关闭作用域的订阅、定时器和查看器归零；应用共享资源和仍运行任务回到对应稳态，不要求所有全局计数归零 |
| 长时间运行 | 60 分钟混合使用与空闲 | 活动订阅、定时器、图片、文档句柄趋于稳定，缓存均不超过对应预算 |

优化不得以删除历史、裁切最终回复、丢弃附件或关闭用户仍在运行的任务实现。若专项指标未达到，修复或重新确定有测量依据的目标后才能关闭该阶段。历史计划中的 70,000,000 字节门槛不直接作为本计划的进程内存目标。
