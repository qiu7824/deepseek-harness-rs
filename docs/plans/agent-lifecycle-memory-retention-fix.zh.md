# Agent 生命周期与内存保留

适用版本：0.1.3-alpha.27。

## 所有权修复

已确认的保留链覆盖 Agent 自引用、工厂活跃实例列表，以及 GoalService 的会话缓存。仅修复前两处时，Agent 可以析构，但每一代 Session 的完整历史仍被目标服务持有；持续恢复同一会话会累计多个历史副本。

ReactLoopAgent 不再缓存包含自身 Arc 的 AgentEventDispatch。每次派发使用局部对象；异步事件可以在处理期间持有 Agent，但 Agent 自身不保存该反向强引用。

PreparedAgent 保存对工厂的 Weak 引用。销毁流程依次停止驱动、释放作用域、注销 Agent 和 Session，再通过 Arc 实例身份移除工厂记录。移除对象在锁外释放，工厂记录更新早于完成信号。相同会话 ID 的不同代实例不会互相删除。

GoalService 原先把 TypeScript WeakMap 改为强引用 HashMap，却没有对应的退役清理。agent/created 会为所有会话建立条目，即使没有创建目标。现在通过 session/disposed 按确切 Session 身份删除缓存；晚到读取不重新缓存已分离对象，在途变更只保留操作自身所需引用。

Cordis 手动注销监听器与插件的释放句柄改用 Weak，避免父级资源列表继续保留已释放载荷；会话不变量的预提交观察使用 Weak 并在退役时清理；投影读取不重新建立已退役会话的缓存；控制请求租约结束后重新触发空闲退役。

## 失败、取消与竞争

- 发布前事务持有回滚守卫。setup 失败、注册失败、announce 失败及创建 future 取消都进入同一幂等清理路径。
- 取消创建时同步启动后台清理；工厂仍持有准备中的实例，停机可以等待其销毁。
- 工厂关闭接收与活跃列表快照使用同一互斥协议，prepare 不能在集合排空后加入新实例。
- 多个销毁等待者共享结果。正常完成和清理异常分别记录；异常不会伪装成成功，也不会无条件丢弃最后一个拥有者。
- 已报告失败的清理允许再次尝试；注册项释放句柄在成功前保留。
- announce 结束后再次检查 closing，关闭中的实例不能重新发布驱动。

原有终端、后台任务、子代理及电脑控制的活动判定继续决定能否退役。释放历史副本不能以丢失队列消息或提前关闭活跃任务为代价。

## 其他内存路径

| 路径 | 边界 |
|---|---|
| 终端自然退出 | 自动注销并关闭后台会话 |
| 模型创建持久终端 | 每拥有者最多三个 |
| 大块终端输出 | 有界截断后回收异常放大的字符串容量 |
| 文本读取 | 流式计数，只保存请求行窗口；超长单行只保留前缀 |
| 沙箱权限准备 | 相同目录与模式共享任务；超时不产生重复 blocking 工作；最多两个工作线程并行 |
| 子代理侧栏 | 独立地址、取消信号和轮询生命周期；关闭后释放请求和正文视图 |
| 计划预览 | 最多八份有界文本快照；失效标签返回明确状态 |
| WPS 预览 | 有界转换队列、单工作者、内容版本缓存及自动化进程看护 |
| 回合文件快照 | 不持有 Agent；只保存有界内容，结束后删除基线，历史审阅缓存有数量上限 |

## 回归证据

`agent_memory_retention` 使用真实 ReactLoopAgent 与本地模拟模型，通过 Weak 引用观察最终析构。

| 场景 | 通过条件与结果 |
|---|---|
| 直接创建、不发送消息 | 最后一个外部引用释放后 Weak 失效 |
| 正常响应与请求失败 | 驱动确实执行、turn/end 存在，随后 Weak 失效 |
| 同一工厂连续 100 代创建与销毁 | 工厂仍存活；每代旧 Agent 均释放，注册表归零 |
| 同一会话 50 次真实持久化恢复 | 使用 JSONL 后端恢复不断增加的历史；旧 Agent 逐代释放，最终历史仍包含全部 50 份载荷 |
| 公开句柄销毁与工厂退役并发 | 共享清理，调用均结束，不残留旧对象 |
| setup 错误与创建取消 | 原错误保留，未发布实例回收，注册表为空 |

完整 Host 的真实 RPC 回归同时观察 Agent 和 Session 的 Weak，覆盖创建、选模型、发消息及自动空闲退役。GoalService 回归覆盖同一会话 ID 的 100 代缓存清理及退役后晚到读取。

代理层已有空闲退役回归继续检查运行中 Agent、活跃终端、后台作业和子代理结果投递的保护边界。

## 内存判据

响应字节发送后及时释放，大响应与最后一个 Host 句柄释放时触发分配器回收；工作线程及主运行线程在空闲时继续执行回收。准备会话缓存同时限制事件数和估算字节，取消读取会释放占用；历史窗口按确切长度重新分配，避免少量返回事件保留整份日志的 Vec 容量。前端最多保留八个未观察的非活动历史窗口，总预算为 32 MiB，并保护草稿、队列、审批和滚动锚点。

固定真实历史的对照实验记录在[生命周期与内存审计](../memory/lifecycle-audit-20260920.zh.md)。该实验中，空闲 30 秒私有内存由 65.88 MiB 降至 43.43 MiB；工作集由 60.34 MiB 变为 64.33 MiB，不能据此声称工作集下降。临时峰值、异常日志回退以及浏览器进程仍需分别测量。

旧 Agent 与其 Session 的 Weak 同时失效是主要判据；仅看注册表数量或工作集回落不足以证明释放。合法的当前会话历史、数据库缓存和在途任务仍会占用内存，分配器也可能保留可复用页。

固定规模负载用于观察预热后私有内存、线程和句柄是否收敛；历史增长负载用于确认旧代副本释放，不要求当前历史所需内存恒定。若出现新的增长，须按分配来源、队列深度和运行实例身份定位，不能把全部增长归因于已修复的引用关系。

## 兼容性

不改变会话磁盘格式、消息顺序、模型请求语义及用户权限选择。更新程序后需要启动新进程，旧进程的存量对象不会因替换磁盘文件自动释放。
