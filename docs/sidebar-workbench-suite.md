# 侧栏工作台扩展套件

`dsh-sidebar-workbench-suite` 通过公开的 `betterSidebar` 服务注册页面和文件查看器。它既是内置增强功能，也是第三方扩展接口的实际消费者；停用该插件会撤销注册，不会改变工作区文件、会话或后台任务。

## 文件工作台

- CodeMirror 6 作为同源懒加载资源提供行号、语法解析、查找、历史、撤销、重做、缩进和键盘编辑。支持 JavaScript、TypeScript、JSON、Markdown、Python、Rust、HTML、CSS 及常用文本格式。Markdown 与代码草稿按会话和路径保存在有界内存缓存中，移动窗格或浮窗重挂载不会丢失；单项草稿与基线合计上限 4 MiB、总缓存上限 8 MiB。容量不足时保留已经缓存的脏草稿并拒绝缓存当前编辑，当前查看器会明确提示先保存再移动。
- Markdown 预览使用 Marked 的 GFM 解析和 DOMPurify 清理。原始脚本、iframe、对象、表单及内联样式不会进入预览 DOM。
- Mermaid 11 以 `securityLevel: strict` 在本地渲染，支持 Mermaid 自身接受的图表语法。编辑器首次需要对应能力时才读取资源，不访问外部 CDN。
- Markdown 大纲、源码／预览／分栏、查找替换、`Ctrl+S` 及 ETag 冲突保护共用一个文件会话。JSON、CSV 与 TSV 可以表格方式查看；常见 Office 和归档文件提供受工作区边界保护的下载入口。

## 任务页面

- 后台任务页读取所有者校验后的 Host `job-list` 投影，合并显示当前与归档任务；运行中每 1.5 秒刷新，空闲每 15 秒刷新，页面隐藏时暂停。增量输出使用独立的非消费游标，完成后停止读取，终止后立即刷新列表。

## Computer Use

设置中的“Computer Use 与远程设备”管理 UU 账号下的设备绑定。未安装时提供安装入口，未登录时提示打开 UU 客户端登录。绑定后在 Computer Use 工作台发起连接；账号切换后旧绑定失效。

受控浏览器页与模型的 `computer_use` 工具使用相同的 `{ ownerSessionId, browserSessionId }` 隔离键。Host 元数据、侧栏和模型工具的默认 `browserSessionId` 均为 `default`，因此模型未指定 ID 时与侧栏看到的是同一浏览器会话。

页面支持点击、双击、拖动、文本输入、组合键、滚动及关闭会话，浏览器还支持导航。点击位置按照控制器报告的视口与显示尺寸换算。浏览器自动刷新默认关闭，开启后仅在页面可见时每 3 秒获取截图；本机桌面使用串行截图请求，隐藏页面时停止刷新，获取失败会移除旧图并禁用坐标输入。网页保留完整键盘与鼠标操作入口，支持适应窗口和原始尺寸显示。

“人工接管”会取消智能体尚未完成的操作，阻止其继续获取画面或发送输入。直接操作画面、聚焦输入框或启用私密输入也会进入接管状态；只有用户点击“交还智能体”才能恢复。浏览器状态不返回密码字段的值，私密输入框不保存草稿。模型的修改动作继续经过工具审批。

Windows 的 `native-desktop` 适配器由独立的 `dsh-desktop-controller.exe` 进程承载。截图直接使用 Windows Graphics Capture，键鼠操作使用 Windows 原生输入接口；无需 UU 登录、UU SDK 或 Node.js。默认观察本机主显示器，可使用 `windowId` 限定窗口。一个物理桌面同一时间只允许一个应用会话控制，失败和关闭会释放进程及归属。

窗口菜单列出可见的非最小化窗口；选择后点击“重新连接”才切换控制目标。模型可通过 `list_windows` 查看窗口，再关闭原会话并连接指定 `windowId`。`focus_window` 只激活已绑定窗口并返回截图，不能解除人工接管。网页中后台窗口的首次点击只激活并刷新画面，不重放旧坐标；同机浏览器失焦后，物理键鼠直接由目标窗口接收。

模型输入后，截图会丢弃操作前的排队帧；静态窗口停止产生新帧时重新建立捕获会话，避免用旧画面判断操作结果。窗口尺寸变化时重建捕获缓冲区，并按有效内容区域裁剪。`waitMs` 控制操作后的等待时间，支持取消。画面超时表示结果尚未观察到，不表示输入没有执行，应先重新观察再决定是否重试。

本机物理键鼠活动会暂停智能体输入，用户需主动交还控制权；监听不可用时禁止启动智能体控制。桌面锁定或处于安全界面时，截图及输入返回错误。窗口移动后必须重新观察；已绑定窗口的鼠标操作会检查实际屏幕位置属于该窗口，遮挡或窗口禁用时拒绝输入。

`uu-desktop` 使用独立的 `dsh-uu-controller.exe` 进程加载已安装 UU 的传输组件，连接当前账号下已绑定的设备。画面在 Rust 自建的渲染窗口中接收，再显示于工作台；不需要打开官方控制窗口。支持旧版及新版 GameViewer；控制进程读取 streamer 导出的接口表与实际版本。画面按 SDK 报告的实际视频区域裁剪，避免宽高比不同造成点击偏移。

UU 工作台使用 H.264 视频、同源 WebSocket 与浏览器 WebCodecs 显示连续画面。SDK 解码后的画面经过 Windows Graphics Capture 和 Media Foundation 编码适配到浏览器；这条链路包含一次重新编码。控制器优先选择系统硬件编码器，使用异步输入输出和低延迟模式；硬件不可用或响应异常时改用软件编码。网页显示保留完整视口分辨率，模型观察单独使用有界截图。渲染窗口位于显示器区域外，不出现在任务栏或抢夺焦点；网页隐藏或暂停播放后关闭视频连接，恢复时从关键帧重新开始。过期视频帧丢弃，解码失败不保留可点击的旧画面。

点击 UU 画面即可直接输入键盘、使用左右键、拖动及滚轮，支持粘贴和输入法文本；全屏模式在浏览器支持时申请键盘捕获。键鼠请求按序执行，鼠标移动合并，输入不等待截图。画面聚焦时，Esc 释放键鼠并暂停智能体；本机全局急停使用 Ctrl+Alt+Esc，其他窗口中的普通 Esc 不会暂停 UU。急停注册失败时保持人工模式。失焦、切换页面及关闭连接会释放按住的键鼠；连接失去活动后还有控制器端释放保护。工作台显示实际暂停原因，沿用原生按钮，不额外显示文本发送框和 Enter、Tab 模拟按钮。

本机桌面与用户共享物理鼠标、键盘和前台焦点，在其他本机窗口操作也会暂停本机智能体控制。连接另一台 UU 设备时，本端其他窗口的普通键鼠操作不会触发全局接管；UU 自连仍操作同一个物理桌面，不能作为两套独立键鼠并行使用。

UU 的设备绑定只影响远程适配器；本机适配器始终控制运行 Host 的电脑。UU 自连是否可用取决于服务端受理结果，连接被拒绝时返回具体错误，不自动改用其他设备。远程输入仍需在解锁后的目标桌面完成验证。

`uu_terminal` 使用官方 CLI 管理已绑定设备上的独立交互式终端，提供 `open`、`read`、`write`、`close` 和 `list`。打开、输入和关闭经过审批，终端归属于创建它的对话；输出使用有界缓存与独立游标。强制新建、完成握手且仍然存活的专属 CLI 连接确认后才允许输入；`remoteSessionId` 可以为空，不会猜测远端 ID。同一设备只保留一个活跃的 Host 终端连接，连接期间不通过另一个 CLI 查询会话列表。

执行命令后应先 `read`。`close` 仅在最近一次读取仍处于原始 Shell 提示符、没有未提交输入时，向该自有连接发送 `exit`；正常退出与远端库存恢复到打开前基线均确认后，`cleanupConfirmed` 才为 `true`。无法确认命令边界、退出失败、库存变化或核验失败时只报告清理未确认，不删除未知远端会话。取消或 Host 退出只清理自有本地连接，不自动提交 Shell 命令。CLI 报告连接被其他窗口接入（2001）后立即停止输入，不自动重新附着；需要登录或解锁时不发送命令或凭据。

Computer Use 未启用、执行器不可用或会话不存在时，Host 返回明确错误，设置页仍可修正配置。已有的冷会话无需加载完整历史即可打开控制环境。普通网页预览独立使用 iframe。

## 资源加载

大型编辑器、Markdown、Mermaid 与终端资源由插件清单声明，Host 只提供包目录内、名称安全、大小受限的 JavaScript 文件。每个插件最多声明 16 个资源，单个资源上限为 8 MiB、合计上限为 32 MiB。资源目录同时绑定插件身份以及主入口和全部资源内容的摘要，任一资源改变都会生成新的入口修订号和 URL，也不会与内容相同的其他插件互相覆盖。资源与主入口同源，响应禁止 MIME 嗅探并使用 `no-store`；插件停用后撤销界面与注册；当前 Host 保留静态资源，重新启用可恢复同一修订。

发布包已经包含这些浏览器资源。npm、打包器和 Node.js 只用于维护者重新生成静态资源，用户运行 Rust Host、侧栏、终端和受控浏览器时不需要 Node.js；PTC 代码模式仍遵循它自己的可选运行依赖。

维护静态资源时，将 `vendor-src/package.json` 与锁文件复制到外部构建目录，执行 `npm ci`，再运行 `python tools/build_sidebar_assets.py --node-modules <外部目录>/node_modules`。构建会核对依赖版本，更新资源摘要和随包许可证。
