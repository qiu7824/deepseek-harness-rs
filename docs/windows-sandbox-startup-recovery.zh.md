# Windows 沙箱启动与权限迁移

## 故障与设计缺陷

`SANDBOX_SETUP_TIMEOUT` 可以发生在业务命令启动之前。已确认的故障场景涉及 48 个私有目录根，父子目录去重后为 47 棵目录树，共 88,956 个文件。私有权限状态保持 `version=0`、`pending=true`、`migrated={}`，原生日志完成公共读取权限检查后，没有记录私有权限迁移完成。

| 设计缺陷 | 后果 | 处理机制 |
| --- | --- | --- |
| 显式递归逐个修改 ACL，同时由 Windows 权限 API 自动向后代传播 | 同一后代被多次处理；目录越深，重复工作越多；尚未核验的链接后代也可能提前受到传播影响 | 使用 `MAXIMUM_ALLOWED` 句柄抑制自动传播，由受控遍历逐个核验和更新；补全等价的继承拒绝规则 |
| 每个对象都重新规范化全部私有根与授权路径 | 大量重复字符串分配、大小写转换和前缀比较 | 每次迁移预先规范化策略路径 |
| 只有全量迁移结束后才保存完成状态 | 启动被中断后，下一次从头扫描所有私有目录 | 持久化待处理队列、已处理数量、账户权限范围和目录权限指纹；每 256 个对象或 2 秒保存检查点 |
| 把所有策略变化都视为同一种初始化变化 | 切换解释器、增加附件或临时目录时，已经完成的迁移工作失效 | 公共程序路径不参与私有权限策略指纹；私有授权变化时重算旧、新授权及其祖先的权限，保留已完成的默认拒绝迁移 |
| 各执行入口统一使用 120 秒绝对启动期限 | 正在持续推进的大目录迁移被误判为挂起；外层期限还会提前截断原生初始化的 900 秒预算 | 准备、沙箱启动、运行时握手和业务执行分别计时；启动根据可信进度判断停滞，并保留总时限 |
| 阶段事件只有接收端，没有完整发送端 | 错误长期停留在 `runner_initialization`，无法区分锁等待、权限迁移和创建进程 | 桥接进程与权限辅助程序发送阶段事件，迁移检查点发送进度事件并记录计数和路径 |
| 准备阶段取消只终止直接子进程 | 权限辅助程序可能继续运行、占用共享 ACL 锁，与后续重试冲突 | 桥接进程在创建普通子进程前进入带 `KILL_ON_JOB_CLOSE` 的 Job Object |
| Node Worker 初始化与程序执行共用预算 | 短任务可能在模型代码开始前耗尽预算 | `prepare → ready → run` 握手完成后才设置业务执行时钟 |

Windows `SetSecurityInfo` 默认传播可继承 ACE；使用以 `MAXIMUM_ALLOWED` 打开的句柄时不自动传播，见 [Microsoft API 说明](https://learn.microsoft.com/en-us/windows/win32/api/aclapi/nf-aclapi-setsecurityinfo)。迁移器因此必须同时维护后代的等价继承拒绝规则，不能仅删除传播步骤。

## 恢复与权限约束

私有目录状态继续使用权限迁移版本 3，检查点使用独立的日志版本。权限账户、私有根或根对象的权限指纹不匹配时，检查点不能作为已完成权限工作的证明。缺少日志的旧 `pending` 状态执行完整安全迁移。

检查点在修改权限前记录全部已尝试授权；只在当前对象更新和子目录枚举均成功后前移工作队列。中断最多重放未持久化批次。重试期间增加附件、修改读写授权或撤销旧授权时，恢复器重新处理所有旧、新例外及其导航祖先，完成撤销后才允许启动业务命令。

目录导航只允许读取属性和遍历，不允许列出私有祖先或读取旁支内容。真实文件访问回归覆盖只读文件、可写目录、嵌套私有根、旧授权撤销、多个账户之间的导航权限保留以及新建文件的继承权限。主机、管理员、系统和其他账户的无关权限项必须保留。

迁移使用文件句柄核验真实路径，拒绝通过硬链接改写其他文件，拒绝把别名目录用作私有根，并且不沿重解析点进入外部目录。权限未准备完成时，业务命令保持未派发状态。

## 启动期限

| 阶段 | 期限与计时依据 |
| --- | --- |
| 环境准备 | 最多 1,200 秒，覆盖原生初始化及前后状态探测 |
| 共享 ACL 锁等待 | 辅助程序最多等待 900 秒，主机使用单独的准备预算 |
| 沙箱就绪等待 | 连续 120 秒没有可信进度时失败；持续有进度时最多运行 1,800 秒 |
| Node Worker 握手 | 沙箱就绪后单独保留 120 秒 |
| 业务命令和模型程序 | 从就绪或实际派发后开始使用各自原有执行预算 |

延长启动等待只接受主机拥有的事件。标准输出、标准错误和模型文本不构成就绪或进度证据。进度事件采用自动复位，已经消费的信号不能持续续期；总启动时限始终有效。

## 验证

2026-10-08，在 Windows 实机上完成以下相关测试：

- 49 项沙箱服务、PowerShell、终端和 Node 执行测试。
- 19 项环境选择与探测测试，包括持续推进超过 120 秒的初始化。
- 21 项私有 ACL、导航权限、授权撤销、链接保护和中断恢复测试。
- 26 项原生桥接、设置辅助程序与进程清理测试。
- 1 项大目录压力测试：48 个私有根、90,000 个文件、90,137 个文件系统对象，首次迁移 43.74 秒；重复检查不扫描后代，耗时 72.1 毫秒。

共 116 项相关自动化测试通过。压力测试使用独立合成目录，耗时不包含生成与清理测试文件的时间，也不等同于原故障目录的前后对照测量。另以真实原生桥接程序验证阶段事件、进度事件的消费行为，以及状态查询不会错误发出命令就绪信号。

需要预置专用本机账户环境的额外集成用例不计入上述通过数量。原生三个辅助程序按同一源码集合构建，并通过构建身份和文件哈希一致性检查；部署时必须成组更新。
