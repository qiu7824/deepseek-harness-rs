# Windows 内存生命周期核查

日期：2026-09-20。证据：[机器采样记录](lifecycle-audit-20260920.json)。

## 结论与测量范围

内存偏高包含临时分配回收延迟、历史页的重复分配及缓存保留。工作集下降不能单独证明对象释放；私有提交量、对象所有权、缓存容量和请求取消均需分别核验。

使用正式安装的 alpha.23 二进制与同一源码基线叠加内存修复的优化构建，二者旁边放置同一套安装资源，读取同一份真实历史副本并使用隔离配置；未复制正式用户设置与凭据，未调用外部模型。启动采样发生在首个 RPC 前。选取序号最高的三个会话，对尾页、前页、后页分别重复读取 10 次，共 90 次历史请求，另有 5 次列表请求。最后单独读取一个大于 256 KiB 的历史响应，然后停止全部 RPC，在 0、1、3、10、30 秒记录进程计数器。两组十个历史窗口的事件摘要完全一致。

| 指标 | 基线 MiB | 修复构建 MiB |
|---|---:|---:|
| 启动后静置 5 秒：私有内存 | 158.37 | 34.80 |
| 历史读取采样峰值：私有内存 | 229.65 | 202.32 |
| 结束后无 RPC 静置 30 秒：私有内存 | 65.88 | 43.43 |
| 结束后无 RPC 静置 30 秒：工作集 | 60.34 | 64.33 |

## 缺陷及处理

| 路径 | 原因 | 处理与约束 |
|---|---|---|
| HTTP 响应销毁 | Drop 回调先运行，Vec 字段随后才析构，回收发生过早；大响应分支也在响应结束前回收 | 最后一个响应所有者释放后，先销毁字节存储，再请求回收；取消与 Bytes 克隆同样覆盖 |
| 工作线程与主线程空闲 | 请求回收代号未变化时完全跳过回收；Runtime::block_on 主线程不执行工作线程休眠钩子 | 工作线程每次休眠前执行非强制回收，主线程用根 future 内的一秒定时器处理自身堆；明确请求时强制回收，不清空 Windows 工作集 |
| 准备会话缓存 | 4096 条事件上限无法约束单条大结果；加载期间取消请求会绕过返回处的容量检查 | 增加每项 8 MiB 的估算载荷预算，保留原有数量上限；读租约结束及后台加载结束均清理无人使用的大项，保留独占预约 |
| 历史分页 | 深拷贝选中事件叠加扫描缓存；直接移动 collect 又可能继承完整扫描数组容量 | 按窗口大小预分配新数组并逐个移动事件；回归同时校验容量和载荷地址 |
| 浏览多个会话 | 单会话窗口有界，但已访问会话的窗口总量没有上限 | 无观察者、非运行中的历史窗口最多保留 8 份，估算总载荷不超过 32 MiB；草稿、队列、待答交互和阅读锚点保留 |
| 计划任务事务锁 | 静态表永久持有每个 Agent 的互斥锁 | 表中保存弱引用，最后一个活动或等待租约退出后删除；取消等待不会破坏串行化 |

## 回归覆盖

- 响应正常完成、提前丢弃、最后一个 Bytes 克隆释放，以及底层存储先于回收销毁。
- 主线程回收的执行线程身份、定时唤醒、原任务返回值和任务结束后停止。
- 大量小事件、单条大载荷、准备缓存复用、独占预约和加载期间取消；Weak 检查确认大载荷所有者释放。
- JSONL 与 Zstandard 历史页、前后翻页、失败回合和版本兼容；一万条扫描记录选取四条后数组容量为四，载荷无深拷贝。
- Agent 与 Session 析构、真实 Host RPC 生命周期，以及终端、作业和子代理活动对退役的保护。
- 40 个已访问会话、85 次向前翻页、挂载观察者和运行会话保护、迟到响应失效；使用真实会话组装器检查输入与位置索引清空，并验证阅读锚点恢复。
- 计划任务同一身份并发、等待取消和最后一个租约清理。
- 47 项前端发布门禁，以及独立的子代理恢复检查。
- 独立测试模型执行 100 次创建、应答、删除循环，以及同一会话连续 50 回合；最后停止 RPC，继续采样空闲内存与进程 CPU 时间，原始记录见机器证据的 lifecycle 项。

## 结果解释与边界

历史读取仍有临时峰值：常规 Zstandard 分页路径的扫描上限约为 65536 条来源事件，序列化载荷预算为 64 MiB；Rust 对象、索引和解析缓冲会额外占用空间，该预算并不等于进程内存上限。未压缩 JSONL、损坏尾帧及非标准存储记录的兼容回退仍可能解析更大的日志或记录，未被这组真实压缩历史测量覆盖。运行中的长会话、终端、后台任务及挂载视图属于有效所有者，不以强制退役降低数字。

前端的 32 MiB 是可重建、无观察者历史窗口的估算载荷预算，不是浏览器堆或总工作集上限。现有 Edge 标签页的 JavaScript 堆、GPU 与共享浏览器进程未作独立堆快照；前端证据来自真实代码的 DOM 与对象生命周期回归。

20 毫秒采样不能捕获所有瞬时峰值，短周期收敛也不证明无限时长下不存在其他泄漏。分配器回收依赖拥有内存的线程执行，跨线程延后释放仍可能等待该线程再次运行。
