# Rust 侧栏工作台能力

侧栏使用当前会话的工作区，通过 Rust Host 的文件、Git 和终端接口执行操作。界面注册在原有会话工具区与工作台浮层；设置位于“设置 → 插件 → 插件配置 → 侧边栏工作台”。

## 已接通

| 能力 | 行为与边界 |
| --- | --- |
| 工作台全屏 | 铺满应用窗口，退出按钮或工作台内的 Esc 恢复普通宽度；编辑区不会因切换全屏重新挂载。采用应用内布局，不调用浏览器或操作系统全屏接口。 |
| 拖动宽度 | 左边缘拖动即时预览，松手按终点保存；取消、失去指针捕获、关闭工作台或切换会话会清理拖动，取消操作不保存。也支持方向键调整。 |
| 跨会话宽度记忆 | `dsh-better-sidebar.width` 保存到当前 Host 的设置文件，现有会话、新会话和重新打开的页面使用同一偏好。窗口缩小、手机断点和全屏不会覆盖桌面宽度。 |
| 保存反馈 | 保存经过现有设置服务的修订检查。失败会保留未保存宽度并显示错误，可重试或恢复已保存宽度；只读连接不会伪装成保存成功。 |
| 内置字段声明式设置 | 字段声明驱动开关、数字和选择控件；Host 对类型、范围和枚举进行校验。保存后实时生效。 |
| 第三方页面注册 | 客户端插件可通过 `ctx.betterSidebar.registerTab()` 注册页面；支持排序、可用性、单例或自定义去重、定向打开、徽标、URL 接管及打开／激活／关闭生命周期。注册返回幂等 disposer，插件卸载后保留的标签显示可恢复占位。 |
| 第三方文件查看器 | `registerFileViewer()` 支持扩展名、优先级、内容探测，以及 `none`、`fsRead`、`mediaUrl`、`custom`、`binary-download` 五种加载策略。禁用或卸载查看器后会回落到下一个匹配项或内置查看器。 |
| 扩展声明式设置 | 每个第三方页面和查看器都有启停开关；描述符可声明 `toggles`、`pluginToggles` 或自定义 `render`。插件本地值保存在 `pluginSettings[descriptor.id]`，并经过 JSON 类型与大小边界检查。 |
| 双工作台与分栏 | 文件、Git、网页预览、终端和第三方标签都可同时停靠在右侧栏和底栏；拖到窗格边缘会创建横向或纵向分栏。相邻窗格的分隔条支持指针和键盘调节，每个窗格至少保留 120px。拖动只更新本地预览，松手后写盘；取消、失去指针捕获、隐藏或卸载会恢复初值。 |
| 自由浮窗 | 内置与第三方标签均可移入应用内浮窗，再停靠回右侧或底部。浮窗支持置顶、拖动、指针及键盘缩放；位置和尺寸经过视口约束并随会话保存。 |
| 移动端文件树 | 视口宽度不超过 768px 时采用全宽工作台，隐藏拖动条，文件树通过抽屉按钮打开，选择文件后收起；返回桌面恢复保存的宽度。 |
| 会话状态隔离与恢复 | 文件、网页、第三方标签、`splits`、`bottomSplits`、底栏高度及 `floats` 几何按会话写入 Host 设置，最多保留 16 个会话布局；刷新页面后恢复。临时全屏、移动抽屉和未选择“记忆宽度”的拖动值不写入布局。 |
| 文件操作 | 工作区目录浏览、源码定位、文本编辑和带版本检查的保存；支持图片、音视频、PDF 与 HTML 预览。 |
| Git 工作台 | 自动发现工作区内的仓库与子仓库，并只接受仓库声明的有效 linked worktree；状态、分支、暂存、取消暂存、提交、推送、放弃更改、分页历史、提交差异、拣选和还原均指向当前原子选择。差异支持工作区／暂存区、统一／并排、hunk 导航和选行复制。 |
| 交互式终端 | Rust Host 分配真实 PTY，界面使用随包的 `@xterm/xterm` 5.5.0 渲染 ANSI/VT，并支持原始键盘／IME／粘贴输入、Ctrl+C 等信号、终端尺寸同步、有界滚动记录和进程退出状态；增强资源加载失败时回落到内置 ANSI 屏幕模型。Windows 默认启动系统 `cmd.exe /D /Q`，不依赖 Node.js；PowerShell 仍可从终端显式启动或使用独立 `pwsh` 工具。终端标签可固定到当前工作区或全部会话，固定信息跨页面恢复；关闭标签会终止对应 PTY。 |
| 网页预览 | 支持多个网页标签、地址导航、前进、后退、刷新和在新页面打开；内容使用沙箱 iframe，是否允许嵌入由目标网站决定。 |
| 受控浏览器 | 与模型 `computer_use` 工具共用同一 Rust 执行层和所有者边界；侧栏可以启动、导航、查看实时截图、点击、双击、输入、滚动、刷新及关闭受控会话。默认会话名统一为 `default`，因此人工接管后模型可以继续操作同一页面。浏览器不可用时 Host 仍可冷启动并通过元数据返回诊断；后台回收器会清理意外退出的进程会话。 |

## 设置字段

| 字段 | 默认值 | 生效方式 |
| --- | --- | --- |
| `width` | 680px | 桌面宽度，范围 420–1600px；实际显示受当前视口限制。 |
| `rememberWidth` | 开启 | 开启时保存后续拖动；关闭时拖动只在当前页面内保留。 |
| `fullscreenOnOpen` | 关闭 | 下次打开工作台时采用全屏布局。 |
| `showFiles` / `showGit` / `showBrowser` / `showTerminal` | 开启 | 控制新导航入口，已打开页面保持渲染，以免打断编辑或终端。关闭后重新打开工作台时只选择可见入口。 |
| `httpLinks` / `httpsLinks` | `sidebar` | 可选择侧栏或正常打开链接；网页入口关闭时链接回落浏览器原有打开行为。 |
| `tabsEnabled` / `viewersEnabled` | `{}` | 仅显式 `false` 禁用对应第三方页面或查看器；未记录的扩展默认启用。 |
| `pluginSettings` | `{}` | 按描述符 ID 保存第三方设置对象。单个值必须可 JSON 序列化，客户端限制单项与总文档大小。 |
| `sessionLayouts` | `{}` | 保存最近 16 个会话的活动页面、文件／网页标签、导航历史和第三方标签元数据。Host 同时校验字段类型、长度和数组数量。 |

显示开关不授予或撤销工具权限。文件、Git 和终端操作继续使用 Host 当前的工作区边界、沙箱与审批策略。

## 上游能力映射

| 与 [DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) 的能力映射 | Rust 侧栏状态 |
| --- | --- |
| 文件编辑与 Markdown 工作台 | 已接通 companion 查看器：CodeMirror 文本编辑与版本检查保存、Markdown 大纲、Marked + DOMPurify 渲染、Mermaid、JSON／CSV／TSV 表格，以及本地 Office／压缩文件下载入口。图片、音视频、PDF 与 HTML 继续使用内置查看器。 |
| 第三方 `registerTab` / `registerFileViewer` | 已接通：注册、匹配、打开、激活、更新、关闭、订阅、生命周期与卸载恢复均可用；同一第三方标签可在右侧、底部、分栏、浮窗和移动端合并抽屉中使用。 |
| 第三方描述符附带声明式设置 | 已接通：支持 `settings.toggles`、`pluginToggles`、`render` 及 `prefs.pluginSettings`。Rust 版本额外识别可选 `defaultValue`；上游未声明该字段的描述符保持原有缺省规则。 |
| 右侧栏与底栏双工作台、拖拽分栏、自由浮窗 | 已接通内置与第三方标签布局：支持跨面板拖放、边缘分栏、比例拖动、底栏高度、浮窗移动／缩放／重新停靠以及键盘操作；窄屏合并为一个全宽抽屉，桌面布局保持在磁盘中。 |
| 后台任务与子代理 | 工作台显示后台任务的状态、输出与终止交互；子代理使用会话头部的原生入口，查看层级、活动、历史并继续或中断任务。 |
| 标签与布局的磁盘持久化 | 已接通：文件与网页标签、扩展标签、右侧 `splits`、底部 `bottomSplits`、底栏高度、浮窗坐标／尺寸、活动窗格及扩展 `meta` 按会话恢复；Host 校验树深、窗格数、标签数和几何边界。 |
| 模型浏览器控制 | 已接通独立 Edge／Chrome／Chromium 执行层和受控浏览器页面：支持隔离会话、URL 与页面状态、实时截图、点击、双击、输入、滚动、导航、关闭、审批、取消、超时及侧栏人工接管。普通网页 iframe 继续承担人工预览，两类页面在界面中明确区分。 |

工作台全屏与恢复是 Rust 侧栏的应用内能力；所核对的上游实现只有面板展开、折叠与视口宽度布局，没有对应的全屏／恢复按钮控制逻辑。
