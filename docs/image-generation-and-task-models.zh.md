# 图片生成与任务模型

任务分工是可选设置。未指定时，任务使用当前对话的模型连接；只有需要专用模型时，才在 **设置 → 模型 → 任务分工** 中指定排错、优化、看图或生图用途。连接和模型可分别留空，凭据始终复用已有账号。

主模型的默认值用于新对话；已有对话保留当前模型。排错、优化和看图通过 `consult_model` 获取辅助分析，由主模型继续执行文件和工具操作。看图模型需要支持图片输入。

## 生图连接

`generate_image` 默认复用当前对话的连接，并选择该连接目录中的生图型号；目录未声明时使用 `gpt-image-2.5-sunburst`。配置生图分工后，仅覆盖已填写的连接或模型。当前连接仍需实际提供图像生成接口。OpenAI Images API 及兼容连接使用图像生成、图像编辑接口；可选择服务端支持的 `gpt-image-2.5-sunburst`、`gpt-image-2.5-flare` 或其他兼容生图型号。普通聊天模型不会因为填入生图用途而自动获得图像输出能力。

选择 ChatGPT / Codex 订阅连接时，请求使用该连接的 Responses 图像工具与账号凭据。订阅是否支持具体生图型号取决于服务端权限；不支持时明确报错，不自动换成另一连接或付费 API，也不使用代码绘图代替生成结果。

接口能力和账号权限分别核验。接口测试通过不表示所有订阅均有 GPT Image 2.5 权限，也不代表所有 Node 社区插件的供应商协议和工作台功能均已兼容。

## 在对话中使用

1. 描述图片内容、用途和约束，主模型调用 `generate_image`。
2. 生成图片出现在当前对话，可点击放大并下载原图。
3. 点击 **继续编辑**，填写修改要求；请求发送到同一对话并返回最新消息位置。
4. 也可直接在对话中说明修改对象。已有生成图可通过其文件名或附件标识继续作为参考图使用。

支持多张参考图和可选 PNG 蒙版。工作区之外的参考图应先上传到当前对话；蒙版尺寸必须与第一张参考图一致。一次最多生成四张图片，编辑结果保留为新的图片，不覆盖原图。

生成图、参考图和会话关联保存，日志导出包含这些附件。预览按可见区域加载，离开区域或关闭对话后释放对应图片 URL。接口超时、取消和失败不会自动触发新的付费生成请求。

参考：[OpenAI 图像生成 API](https://developers.openai.com/api/docs/guides/image-generation)、[GPT Image 2.5 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)。
