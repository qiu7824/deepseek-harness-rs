## 会话历史兼容

升级到 Session V4 后，`session.list` 曾只保留当前格式版本，导致仍在磁盘上的 V3 会话从 Web 和 Flutter 列表消失。列表改为使用持久化层已经验证的可读会话，不再按当前写入版本过滤；未挂载投影缓存时也读取真实的空白状态和更新时间。

冷启动构建列表时，用户消息导航与列表元数据使用同一代历史。读取 V3 导航不再在投影重建途中迁移到 V4，避免发生“projection source identity changed”。正常压缩 V3 日志在列表读取前后保持原始字节不变；写入与继续执行仍由持久化层执行相邻版本迁移，并保留旧日志。无效或不支持的历史仍返回明确错误。

列表冷读取折叠标题、模型选择、列表状态、Token 用量和子任务计时，跳过不影响这些字段的流式 token，完整对话投影在打开任务时加载。列表缓存与完整投影分别校验，避免把轻量缓存误当作子智能体身份或完整历史；标题编辑的条件与列表字段使用同一序列水位。

## Flutter 输入与设置

- Windows 支持 `Ctrl+V`、`Shift+Insert` 和输入框右键粘贴图片或复制的文件；PNG 保留透明度，截图位图转换为 PNG，资源管理器复制文件优先于附带缩略图。
- 图片与文件沿用现有附件上传协议、8 个附件和 16 MiB 总量限制；图片像素另有上限。图片显示缩略图，可移除后发送。
- 纯文本仍按原选择范围粘贴。附件读取期间禁止提前发送，切换会话后丢弃迟到导入结果，并发导入不能突破数量上限。
- 历史文本初次显示完整内容；仅在跟随最新消息时逐步显示后续流式追加，停止跟随、完成或隐藏面板时立即显示已收到的全部文字。行内代码使用可选择文本，窄窗口与双倍文字缩放不再由嵌套组件裁切。
- 右侧工具工作台支持新增、切换和关闭多个标签，保留各标签视图；隐藏标签停止重复读取，切换会话或 Host 后丢弃旧请求结果，终端写入按同一终端顺序完成。
- macOS 与 Linux 的原生图片剪贴板尚未接入，文本粘贴继续使用平台默认行为。
- 技能与 MCP 管理支持编辑、删除、搜索、测试及错误回显；MCP 支持 stdio 与 HTTP、环境变量、请求头和工作目录。保存失败保留编辑草稿，未修改的字段保持原配置。
- 自动经验管理支持全局捕获开关、搜索和过滤、经验启停、建议确认、删除、诊断结论查看及当前任务候选预览；修改使用修订号保护，失败保留草稿，任务和 Host 切换取消旧请求。
- Flutter 团队任务派发／依赖／验收面板、插件安装卸载、技能导入与候选版本管理、诊断人工核查编辑仍未接入；Host 或 Web 已有接口不等于原生客户端已完成。
