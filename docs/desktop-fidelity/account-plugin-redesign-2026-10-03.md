# 桌面账号入口、插件、关闭崩溃与界面细节修复

日期：2026-10-03。基于合并 `codex/reliability-flutter-web-20260928` 后的 Flutter 客户端（`0.1.3-alpha.38`）。

## 排查结论

| 位置 | 问题 | 原因 |
| --- | --- | --- |
| 左下角账号 | 弹出全部订阅服务，多数是“未授权”的不可点行 | Host 的 `/provider-auth/providers` 返回全部 8 个提供方，菜单逐个列出 |
| 左下角账号 | 菜单覆盖触发按钮；“需重新登录”无法直接处理 | 菜单使用覆盖式定位，服务行均为禁用项 |
| 左下角账号 | 未登录时入口完全隐藏 | 仅在已授权时渲染 |
| 插件 | 点“产物预览”跳到输入框而非产物视图；“定时任务”无法打开 | 按 Host 分配的 entryId 匹配，各安装取值不同 |
| 插件 | 侧栏插件页与设置插件页是两套行样式与操作 | 设置页沿用旧列表 |
| 插件 | 720 px、200% 字号的设置插件页底部溢出 46 px | 标题、搜索与计数固定在列表上方 |
| 设置导航 | 工具发现、目录与运行环境、小菜单设置均显示齿轮 | `wrench`、`folderCog`、`listFilter`、`shield` 资源内容实为齿轮 |
| 侧栏 | 会话和工作区菜单只能右键打开 | 无可见入口 |

## 修改

- **账号入口**与设置按钮同一行。面板锚定在按钮上方、左侧对齐，只列出已连接或需重新登录的服务；需重新登录的服务排在前面，并直接提供“重新登录”；点击服务进入该服务的账号设置并展开定位。未连接时显示“登录订阅账号”，一键进入登录页。连接或账号变化时面板关闭，旧操作被拦截。
- **订阅账号设置**分为“已连接”和“可登录的服务”两组，状态用颜色区分，登录与重新登录无需展开即可操作。
- **插件**按模块名打开对应视图；定时任务插件打开定时页。设置插件页与主插件页共用同一列表；启用状态与运行状态合并为一个状态。标题区随列表滚动。主插件页的返回按钮、标题与主按钮与知识库、定时任务页一致。
- **设置导航**分为常用、智能体、系统、数据四组，图标统一来自桌面图标集，四个错误图标已重绘。默认预设在列表加载前显示名称，不再显示截断的 ID。
- **侧栏**：会话与工作区行在悬停或聚焦时显示“⋯”菜单，菜单带图标，删除项为红色。定时、知识、插件入口在大字号下改为图标上、文字下，仍在同一行。窄窗时主页面避开浮动的侧栏按钮。

## 关闭崩溃、旧服务兼容与偏好隔离

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 关闭窗口卡 2–3 秒 | 每次关闭都在 `flutter_windows.dll` 中访问冲突（0xC000041D），Windows 错误报告收集崩溃信息时窗口停留 | `window_manager.destroy()` 只投递退出消息，窗口和引擎留到进程退出时才销毁；现保存后取消关闭拦截并调用 `close()`，由 Windows 在消息循环内正常销毁窗口。`main.cpp` 同时保证窗口在 `CoUninitialize` 之前释放 |
| 窗口底部被任务栏遮挡 | 初始窗口固定 1440×900 | 按主屏工作区居中并留出边距 |
| “服务请求失败 (http-405)” | 客户端连接到旧版本机服务，旧服务对缺失的接口返回无 JSON 的 404/405 | SDK 将其归为 `unsupported`，提示“本机服务版本较旧，不支持此功能（接口名）”；定时任务和知识库页显示更新提示 |
| 测试覆盖真实桌面偏好 | `DesktopPreferences.load(fromFile:)` 及未指定写入器的测试实例写入 `%LOCALAPPDATA%` 下的真实文件 | 从指定文件读取的偏好写回该文件；`test/flutter_test_config.dart` 让测试的默认写入器不落盘 |

## 界面细节

- 侧栏三个入口改为无边框导航块；输入框操作为安静的图标按钮，发送按钮仅在可发送时使用强调色，输入时边框高亮。
- 设置去掉全窗口模糊遮罩（无显卡时由软件渲染，打开关闭明显卡顿）；外观改为明暗主题缩略图。
- 插件列表加分隔线；Markdown 表格改为圆角外框、表头底色与左对齐，代码块去掉双层边框和末尾空白。

## 验证

`flutter analyze` 无问题；全量 Flutter 测试 695 项通过、4 项条件跳过；SDK 测试 96 项通过、4 项条件跳过。新增回归覆盖旧服务 404/405 的提示、关闭流程顺序与重试、测试偏好隔离、行菜单入口及账号面板交互。

Windows Release 构建后，对隔离数据根的本机服务运行实际程序，通过客户端自身窗口句柄发送关闭消息三次：每次约 120–135 ms 退出、退出码 0、系统日志无新崩溃；修复前为 2.2–2.9 s 并伴随两条崩溃记录。窗口位于工作区 (24,24)–(1416,836)。对 2026-09-23 的旧服务复现了 405 提示问题，修复后由 SDK 与页面回归验证。整页视觉帧覆盖 Windows 字体、明暗主题、1440×900 与 720×640/200%；图标黄金图已按重绘图标更新。
