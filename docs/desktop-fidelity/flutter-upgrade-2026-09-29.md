资源场景 Private Bytes 观测峰值为 589.60→408.80 MiB，下降 30.66%；Working Set 观测峰值为 209.92→237.32 MiB，增加 13.05%。候选流式 UI/Raster P95 为 5.067/2.230 ms，均满足 16.667 ms 预算；相对基线帧耗时增加，不能据此声称流式性能提升。构建身份、离散采样与单次对照的限制详见性能基线。

布局回归使用 Windows 实际字体，覆盖浅色/深色、文字缩放 100%—200% 及 720×520 至 1440×1000 窗口；图标黄金图覆盖 1.0/1.5 DPR。测试包含草稿作用域、关闭前保存、快捷键、代码换行、错误恢复、历史锚点、隐藏页回收和异步回调隔离。组件级缩放与合成键盘事件不替代操作系统显示缩放、真实输入法和读屏软件的实机验收。

已安装 Windows 客户端的主界面、已有工作区/会话列表、设置页、弹窗返回和窗口关闭已核对；关闭客户端后 Host 持续运行。原生 Ctrl+K 等组合键的自动输入未得到稳定的可见响应，不能记为实机通过；组件级快捷键与焦点回归仍单独保留。没有向真实会话发送测试提示词。

macOS/Linux 尚未构建并实机验收。真实中文输入法组词、屏幕阅读器、Windows 100%/150% 显示缩放下的系统图标，以及真实 Host/Computer Use 的长时混合负载仍属于后续平台验证范围。当前性能数据为固定测试场景的一组对照，不满足计划中每场景三次重复及 60 分钟混合使用的完整性能认证要求。
