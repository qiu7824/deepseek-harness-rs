## 界面行为

- 左侧使用浅灰底和整行导航，悬停与选中状态分别呈现；插件、定时任务与知识工具可直接访问。
- 左下角保留直接打开的设置按钮。登录后，账号摘要显示在设置上方；单服务显示提供商与掩码账号，多服务使用汇总，未授权时不增加账号行。
- 顶部保留会话、轨迹、产物、代码图谱、上下文五项导航；字体放大时行高同步增加。
- 右上角保留工作台开关，日志下载、反馈、协作和当前定时任务收于更多菜单；菜单按控制器、服务、会话与选择代次核验作用域。
- 插件在主工作区展示，采用图标卡、中文说明、清晰的启用/运行状态、局部黑色添加按钮和浅灰悬停。来源和实验性标记只使用真实元数据。
- 时间上下文配置保持折叠、筛选、列表滚动和重排后的草稿；启用状态修改不删除定时规则或内容。
- 工作台开始页提供工作区文件、新建终端和 Computer Use 入口。无会话时，资源操作仅在显式选择后通过服务创建会话，保留未发送草稿，不自动发送消息。
- 浏览器卡片进入现有 Computer Use 控制环境，功能说明区分浏览器控制与普通网页浏览。
- 会话统计、用量、上下文分别通过浮层查看；回合浮层共用字体、间距、列对齐、单位与键盘关闭行为。

独立项目任务模块已完整退役：Flutter/Web 入口、模型工具注册和自动上下文移除；旧读写接口返回 `410 / feature-retired`，已有 `PROJECT_TASKS.md` 与历史事件保留。普通待办、计划、团队、后台作业及定时任务继续运行。

## 配色与可读性

浅色侧栏 `#f9fafb`，正文 `#0f1115`，悬停 `#f2f3f4`，选中 `#eceef0`，边框 `#dedede`，关闭开关轨道 `#e0e0e0`。蓝色继续表示强调、焦点及相关状态。辅助文字最低计算对比度为浅色 4.8243:1、深色 5.5324:1。

浮层显式继承产品字体及中文回退；窄窗口与大字号下，统计列上下排列并允许滚动查看完整数值。Esc 优先处理当前模态窗口，关闭统计后焦点回到触发控件。
