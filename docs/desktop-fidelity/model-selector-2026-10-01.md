# 模型选择、思考等级与上下文交互

## 请求链路

本机目录包含 8 组、306 个模型，连续 8 次 `session.models` 只读调用耗时 727–765 ms，中位数 739 ms；`host.describe` 约 6 ms。目录接口逐一读取提供商及模型能力，完整目录读取具有可观察成本。

| 原行为 | 改进后的行为 |
| --- | --- |
| 打开菜单先等待完整目录 | 已有目录立即展示；首次缺少目录时在已打开的菜单内加载，多次请求去重 |
| 模型或等级选择串行等待选择、目录、默认保存 | 选择回执确认后立即结束等待；能力数据从已有目录保留，默认保存有序后台执行 |
| 选择等待期间所有选项禁用 | 显示最新待确认目标，连续点击只保留最后意图，实际写入按顺序执行 |
| 滑杆松手先回到旧值 | 离散等级选项直接点击，确认值与待确认目标分别标记 |
| 每次打开模型菜单创建空会话 | 未选模型时仅读取全局目录，实际选择模型后才准备会话 |

目录按 Host、账户及配置范围缓存。账户变更、配置保存与 Host 切换会使旧目录与弹层失效；旧读取、旧选择及旧默认保存不能覆盖当前状态。未知选择结果阻止发送，明确确认或重新选择后恢复。

启动时账户元数据与会话模型读取可能并行完成。账户范围变化使首次响应失效后，已有会话按有效范围补读一次并与在途请求合并；读取失败不循环，仍可显式重试。首次加载会自动出现当前模型与思考入口。

## 交互层级

输入框工具行采用紧邻的“模型”和“思考”入口，分别打开锚定弹层。模型弹层仅承担目录搜索与选择，支持提供商名称搜索、键盘导航、虚拟列表及完整名称提示；选择后立即收起并回到输入框。模型入口显示待确认目标，服务端确认后移除等待标记。

两个入口保持同一行，思考等级预留可读宽度，长模型名在剩余空间省略。窄窗口及大字号下，等级按钮采用精简等级文字，完整说明保留在提示中；真实长型号和“最高”在 100%／200% 字号下均验证同一行。

思考弹层使用当前模型声明的等级，选项至少 36 px 高，可换行并支持键盘操作。提供商默认等级保留在能力数据中，默认、未知及不可调等级分别呈现。等待中可更换意图，确认值不被预览冒充。

上下文组成与自动压缩设置集中到独立“上下文”入口，模型目录中不放上下文参数。阈值支持 Host 的 30%–98% 范围，拖动开始固定会话与确认模型；目标变化后旧拖动失效。保存期间显示待保存值，失败恢复确认值。模型尚未确认或消息正在提交时禁止压缩配置写入。

窄窗口及大字号使用有界弹层和滚动区域，长模型名在入口省略并通过提示完整显示。滚动内容预留 16 px 右侧净空，避免滚动条覆盖数值及按钮。

## 官方实现对照

[DeepSeek Harness 模型菜单](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/packages/client/ui-model-selection/src/client/ModelSelect.tsx) 使用输入框锚定菜单，模型和思考通过不同列表选择；[目录实现](https://github.com/deepseek-ai/deepseek-harness/blob/477b4f420553e8a52c2fbccc464d7561b239c443/packages/client/ui-model-selection/src/client/catalog.ts) 按 Host 世代共享缓存和在途请求。

[OpenCode 输入框](https://github.com/anomalyco/opencode/blob/dev/packages/app/src/components/prompt-input.tsx) 将模型 Popover 与模型 variant Select 放在相邻位置，选择后恢复输入焦点。[官方模型文档](https://opencode.ai/docs/models/) 将 variants 定义为模型的配置差异。

两种实现共同保持模型选择与等级选择紧密关联，避免把整个模型目录放在参数之间；目录更新不要求每次菜单打开重新读取。
