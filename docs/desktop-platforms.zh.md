## 验证边界

最终发布记录须包含源码与构建标识、客户端和 Host 文件摘要、包格式、安装或升级结果、用户数据保留、适用功能和实测证据。Windows 的已安装历史版本或某个平台的构建结果不能代替其他平台验收。

原 70,000,000 字节全过程性能门槛不作为当前版本发布阻塞。2026-09-29 已执行固定负载的资源循环与流式专项，方法、指标和局限见[内存基线](memory/flutter-baseline.md)。测试绑定下的 Release/Profile 结果不等同普通安装版进程占用，也不覆盖 Host、子进程和真实 Computer Use 长时间负载；历史性能结果按构建保留。
