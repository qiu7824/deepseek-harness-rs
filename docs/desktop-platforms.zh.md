# 桌面平台支持与验收

发行结构为 Web 核心版与 Flutter 桌面客户端，共用 Rust Host、会话格式和 HTTP/WebSocket 协议。模型目录、凭据及连接配置由核心能力提供，不按免费模型划分发行版本。

| 平台 | 客户端工程 | 服务与设置目录 | 当前集成版本的交付状态 |
| --- | --- | --- | --- |
| Windows x86_64 | 已集成原有原生客户端 | 同目录 `host`；用户 LocalAppData | 尚未完成完整构建、安装与实际验收 |
| macOS x86_64 / arm64 | 已接入 macOS 工程 | 应用包 `Contents/Resources/host`；用户 Application Support | 尚未完成平台构建、安装与实际验收 |
| Linux x86_64 | 已接入 Linux 工程 | 同目录 `host`；XDG_CONFIG_HOME 或用户 `.config` | 尚未完成平台构建、安装与实际验收 |

文件、对话、任务、设置及预览通过共同协议访问 Host。运行权限、原生控制、Office 自动化和语音取决于具体平台与实际可用组件；平台工程存在或静态分析通过不代表这些能力已经可用。

最终发布记录须包含源码与构建标识、客户端和 Host 文件摘要、包格式、安装或升级结果、用户数据保留、适用功能和实测证据。Windows 的已安装历史版本或某个平台的构建结果不能代替其他平台验收。
