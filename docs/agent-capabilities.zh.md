# Agent 交互、上下文和多媒体能力

## 操作反馈

回复提示默认显示图标和文字，也可选择纯图标或纯文字；已保存的偏好继续生效。

图片、视频和文件操作根据工具状态显示“正在查看图片”“已查看图片”“已编辑文件”等提示，并保留文件名称、结果和可展开详情。错误与取消使用独立状态，不显示成功提示。输入栏顺序为添加、对话链接、附件、权限，四个图标使用一致的尺寸和间距。权限名称可通过悬停说明和菜单查看。

提问支持选项、自定义答案、显式提交、取消及失败后重试。等待回答、提交中和取消中均有可读状态。审批支持拒绝、允许一次及限定范围的授权记忆，重连后继续显示尚未处理的请求。

## 上下文压缩

“设置 → 记忆”中的自动压缩、阈值、保留目标和保护最近消息数量参与实际执行，无需重启。目标比例必须小于触发阈值。预设里的显式压缩配置优先于通用设置。

压缩流程如下：

1. 在模型请求前检查历史与待发送消息的上下文压力。
2. 达到阈值时先裁剪较早的长工具输出，保留头尾和最近消息；裁剪足够时无需调用摘要模型。
3. 按保留目标选择历史区间，避免拆开工具调用与结果，保留系统前缀。
4. 通过摘要模型生成检查点，替换后续模型请求使用的历史视图；原始事件仍保留。
5. 提供方报告上下文溢出时执行有次数上限的压缩恢复；只有上下文实际发生变化后才重试请求。

预设支持 `thresholdRatio`、`retainRatio` 或 `retainTokens`、`summarizationProvider`、`summarizationModel`、`maxTokens`、`compactionRetries`、`maxOverflowRetries`、`protectRecentMessages`、`auto` 和 `modelPolicies`。摘要连接与模型应成对设置，重试上限最多为 10。没有指定摘要模型时沿用会话模型。摘要失败不会静默跳过；取消会中止等待与摘要流，未完成摘要不替换历史。

保护消息数量可能使短会话没有可压缩区间。没有模型上下文容量时无法按比例提前触发，但提供方明确报告溢出后仍可尝试恢复。原始记录保留不等于摘要完全无损；关键约束应继续保存在项目文件或记忆中。

## 搜索服务

“设置 → 插件 → 插件配置 → Web search”支持两种服务：

| 服务 | 连接来源 | 模式 |
| --- | --- | --- |
| DeepSeek | 独立的搜索端点与凭据配置 | 原生服务端搜索 |
| 托管搜索 | 当前会话的已有模型连接；可选的“搜索”任务分工可覆盖 | 实时联网或缓存搜索 |

默认继续使用 DeepSeek。更换服务需要在设置中选择并保存，不会因一次失败自动切换端点或账号。托管搜索要求所选连接支持 Responses 的原生 `web_search` 工具；代码可使用已有 OpenAI API 或 Codex 订阅连接，具体账号和模型是否开放服务由提供方决定。

搜索返回服务端来源及引用，不将无来源的模型回答伪装成搜索结果。正常零命中、原生搜索未触发、提供方错误及不完整响应分别处理。请求审计不包含认证请求头或密钥。配置在每次请求前形成快照，避免等待凭据期间混用不同连接配置。

网页抓取支持受限 gzip、Brotli、deflate 解码及响应字符集，同时限制传输和解压后的数据量。

## 浏览器标签页与上传

原生浏览器适配器支持 `list_tabs`、`new_tab`、`select_tab`、`close_tab`，每个浏览器会话最多 16 个标签页。标签页标识仅在所属浏览器会话内有效。关闭最后一页后仍可创建新页。

`upload_files` 使用文件输入框的 CSS 选择器和工作区文件路径；路径在 Host 指定的工作区内解析，不能通过 `..` 或符号链接绕出工作区。一次最多 16 个普通文件，单文件 16 MiB，总计 64 MiB；空数组清除选择。上传、标签页修改等操作继续服从现有控制与审批策略。

浏览器适配器与 UU 桌面适配器是不同通道。向桌面适配器传入网页 URL 不会被误认为已经打开了隔离浏览器，也不会自动修改用户的适配器选择。

## 视频证据读取

`read_video` 接受以下来源之一：工作区视频路径、可播放的网页 URL、已有原生浏览器会话。已登录网站可以使用已有浏览器会话；不支持的播放页会返回具体失败，不以搜索文字代替视频画面。

- 默认采样 6 帧，一次最多 12 帧，可指定时间点。
- 优先截取实际解码画面，避免播放器控件覆盖；跨域限制下可返回可见视频区域截图，并注明采集方式。
- 返回的每帧包含时间点和持久图片附件，可显示、预览并发送给主模型，也可交给单独的看图模型分析。
- 本地视频可读取相邻的 SRT/VTT 字幕；网页视频可读取已经加载的字幕轨道。
- 本地音频通过 PATH 中的 FFmpeg 提取，再调用已有语音设置中的 STT 可执行程序。单次最多处理前 600 秒音频，转写文字最多 32000 字符，并标记截断。
- 工作区视频上限为 512 MiB，采样图片总量上限为 32 MiB。支持浏览器能解码的 MP4、WebM、MOV、M4V 和 Ogg。

结果明确区分画面、字幕和音频覆盖范围。只查看采样帧不代表看过全部视频；缺少 FFmpeg/STT、远程网页音频未转写、跨域限制或受保护播放时，不声称已获得相应内容。受 DRM 保护的视频不导出解码帧。

## 验证范围

后端库回归通过 351 项测试，另有 36 项真实 Agent 循环集成测试，覆盖溢出恢复上限、取消、设置热更新、工具输出裁剪、系统前缀和重复压缩。原生 Edge 集成验证标签页操作、实际文件选择及工作区边界。前端验证操作状态、提问等待、审批恢复、搜索设置、附件和生成图片交互。

隔离 Host 的端到端验证使用本地模型服务：原生托管搜索返回来源，真实解码视频产生三个不同时间点的画面，读取字幕并提取音频调用 STT，图片最终进入主模型请求。该验证不替代真实订阅账号、远程登录网站及各操作系统的发布验收。
