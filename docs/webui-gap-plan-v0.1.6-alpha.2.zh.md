# Rust WebUI 功能与发布接线

适用版本：0.1.3-alpha.28。界面沿用现有组件、主题和工作台体系。

## 正式加载的模块

| 模块 | 入口 | 后端约束 |
|---|---|---|
| 工具发现 | 设置 → 工具发现 | 保存使用预期修订号；显示实际运行状态 |
| 技能候选与版本 | 设置 → 技能候选与版本 | 创建、读取、验证、启用、撤回、恢复和删除均通过已注册 RPC；激活仍要求可信验证证据 |
| 任务验收与恢复 | 对话视图 → 任务验收 | 只读检查、精确版本、未知效果核实与环境迁移分别处理 |
| 运行环境 | 设置及会话运行环境视图 | 实际程序路径、权限模式、检查缓存和错误阶段分别呈现 |

源码副本、dist 文件和 manifest 的 SHA-256 前缀必须一致。技能版本方法同时登记在 RPC 方法表，避免界面存在但请求返回 404。

## 工作台功能

### 回合文件变化

回合第一步前建立文件基线，turn/end 后完成第二次观察。审阅显示回合编号、文件数、增删行数、开始和结束时的正文及不可比较原因。已有未提交修改属于开始基线，不把 Git HEAD 或当前 Git 状态冒充该回合的开始状态。

快照覆盖 Git 管理的文件及未忽略的新文件；单文件、文件总量和正文预算均有上限。超限、非 UTF-8、二进制及无 Git 基线明确显示状态。观察到的期间变化可能包含同一目录中的并行任务修改，不能据此独占归因。

### 子代理侧栏对话

成员和子代理入口在右侧打开独立子对话，父对话继续保留。地址包含父会话、子会话和 continuable/one-shot 模式；只读记录不提供发送和停止操作。

支持最近消息、排队或引导发送、附件和停止，并提供主区完整历史及审批入口。草稿按地址隔离，关闭或切换后中止请求并释放轮询。附件数量、总字节和草稿缓存均有上限。

### 计划预览

exit_plan_mode 原计划卡提供预览入口。标签显示该次调用的确切 Markdown 快照、标题、复制和返回来源；不生成新计划，不改变批准或拒绝的绑定对象。缓存失效后要求从原卡重新打开，不能显示另一份计划替代原版本。

### Office 预览

DOCX、XLSX 和 PPTX 通过 WPS 转为 PDF，并复用工作台的页数、翻页和缩放控件。源文件只读复制，缓存绑定源文件内容哈希；刷新会重新核对源文件身份。

自动转换禁用宏，并拒绝含活动嵌入内容或外部关系的 OOXML。队列最多四项、单个工作者，PDF 缓存总量受限。自动化进程有明确拥有者及超时看护，不结束已有用户 WPS 文档。

缺少 WPS、已有实例不可独占、旧二进制 Office 格式或转换失败时，提供本地 WPS 打开与下载。PDF 生成只证明转换成功；字体替代和版式仍由 WPS 环境及实际页面检查确定。

### 插件中心

全局“插件”入口统一呈现库存、可用范围、启停、生效状态、配置入口、安装、移除和错误记录。安装与移除复用现有 Rust CLI 验证；仅加载兼容的 Web 部分，不能把 Node Host 插件直接装入 Rust 进程。

修改带有明确确认和重启生效状态。失败保留输入及日志，不把下载完成等同于插件已经运行。

## 控件、图标与配置一致性

账号提供者切换、环境与 SSH 操作、插件中心、工具发现及预览控件使用统一主题样式，覆盖选中、禁用、键盘焦点和窄屏换行。各模块独立管理样式生命周期，不依赖先打开其他页面。

环境探测和清理缓存保留尚未保存的输入及原始修订号；切换会话后忽略迟到结果。项目路径编辑与读取配置分开，读取失败保留编辑入口，中文输入法确认不触发半成品路径提交；未读取新目录配置前阻止写入。

侧栏终端支持重启后的持久会话，打开期间保持拥有者有效，避免与后台空闲回收竞争。终端输入、调整尺寸、信号、退出码和关闭保持原有交互。

启动器、任务栏、托盘及安装包使用同一标准鲸鱼图案。Windows 快捷方式显式引用随包 ICO，安装后刷新 Shell 图标缓存；非 Windows 启动器随包提供标准 PNG。发布校验比较归档图标字节及 Windows 可执行文件嵌入图标的各帧，避免构建资源与托盘图案不一致。

## 恢复操作与权限状态

任务环境变化后，只读取证不会被契约守卫自我阻断。环境迁移是用户控制操作，要求当前契约版本，保留步骤和未知效果并失效旧验收证据。未分派操作显示“请求操作未启动”；已经执行但效果不明的步骤继续要求核实。

## 验收要求

- 从正式 manifest 启动并核对模块哈希，不能仅验证源文件语法。
- 打开、操作、切换会话、刷新后重新打开；保存结果核对 Host 实际状态。
- 计划内容、子代理地址和回合编号保持精确绑定；关闭后无遗留轮询。
- WPS 使用实际导出结果；不能以自建排版器替代 Office 分页证据。
- 新区域覆盖加载、空数据、错误、只读及失效状态，检查中文、窄屏、浅深主题和键盘操作。
- 安装包的版本、构建提交、页面字节及运行实例一致后，才确认安装版交付。
