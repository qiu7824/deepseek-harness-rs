# Devin / Windsurf 订阅连接

在模型设置的订阅账号区域选择 **Devin / Windsurf**，点击登录并打开授权页面。授权完成后，账号和模型目录自动更新；无需安装 Devin CLI，也无需在浏览器界面粘贴访问令牌。

授权回调监听运行 Host 的电脑上的 `127.0.0.1:59653`。登录应在这台电脑的浏览器完成；通过其他设备访问 Web 界面时，可先在 Host 电脑完成登录，再使用已连接的账号。取消登录会释放回调端口，过期或状态不匹配的回调不会保存凭据。

模型列表来自当前账号的服务端目录，保留实际模型标识、名称、上下文容量、输出上限与图片能力。账号未获授权、额度不足或目录不可用时显示相应错误，不使用猜测的 SWE-2 标识替代。不同推理档位若由目录作为独立模型提供，应选择对应条目。需要额外服务端分配步骤的路由模型不出现在此连接的可选列表中。

消息通过原生 Connect/Protobuf 协议传输，支持文本、推理、图片、工具调用、工具结果与服务端返回的 token 用量。请求使用压缩传输；响应解压、帧长度和累计数据量均有限制。推理签名按账号、模型、会话和服务端点隔离，不跨账号重放。

账号凭据保存在 Host 的凭据存储中。新增登录不会删除已有账号；切换账号后使用该账号的模型目录和配置。此连接不提供 Codex 用量查询或重置功能。

## 验收

1. 发起登录后取消，确认能够再次发起授权。
2. 完成真实账号授权，确认目录中出现该账号可用的 SWE-2 条目。
3. 选择模型发送一条短消息，检查连续输出及结束状态。
4. 在测试工作区读取一个测试文件，检查工具调用与工具结果回传。
5. 如需验证图片能力，使用目录明确声明支持图片的模型；检查其能识别图片中的实际内容。

模型权限、订阅额度和服务端缓存效果以账号实际返回为准。服务端模型目录中的缺失容量使用客户端保守默认值，可通过模型设置覆盖。

参考：[SWE-2 发布说明](https://cognition.com/blog/swe-2)、[Devin CLI 模型](https://docs.devin.ai/cli/models)、[Devin 授权说明](https://docs.devin.ai/cli/enterprise/devin-auth)。协议互通参考 Oh My Pi 18.1.18 的公开实现及消息定义，许可见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
