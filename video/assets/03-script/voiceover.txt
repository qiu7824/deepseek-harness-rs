这是 DeepSeek Harness。我用得最多，也最难受的地方，是它得一直挂着。会话一多，Host 的内存很快就上去了。

所以我保留了它原来的界面和工作方式，把 Host 和后端运行时用 Rust 重写了一遍。现在正式入口就是 dsh.exe web。

浏览器里还是原来的 Harness。选工作区，选模型，然后把任务发进去。这个过程没有重新发明一套界面。

这里跑的是一次真实请求。先等模型返回，然后进入 Glob 工具。首 Token、工具耗时和缓存命中率，也都还在原来的会话里显示。

插件也没有被写死进 Rust。上下文跳转、输入框展开和语音输入，仍然是独立的 Web 插件。当前页面里四个插件都已经启用。

我刚在这台机器上连续采了十次。Node Host 加上它的 esbuild 子进程，工作集大约二百一十八兆；Rust Host 是四十五兆左右。这个是当前运行状态，不是同一会话、同一任务的严格基准，所以我不把它说成倍数结论。

项目已经公开在 GitHub，目前还是预发布版。代码、说明和下载包都在 github.com/qiu7824/deepseek-harness-rs。
