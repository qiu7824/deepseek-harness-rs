## 内存数据边界

采样时间：2026-08-24 17:24，中国标准时间。每两秒一次，共 10 次。

- Node Host `node.exe`：Working Set 163.0 MB；Private 226.9 MB。
- Node 子进程 `esbuild.exe`：Working Set 55.3 MB；Private 55.4 MB。
- Node 进程树合计：Working Set 218.3 MB；Private 282.3 MB。
- Rust Host `dsh.exe`：Working Set 45.3 MB；Private 91.3 MB。

这些数据来自同一台机器、同一时段的当前运行状态，但 Node 与 Rust 未加载同一批会话，也未执行同一个任务。因此只能报实际数值，不能称为严格性能基准，不能据此口播“降低几倍”或“节省百分之多少”。

## 本版不再宣称的能力

本轮素材没有真实覆盖以下能力，因此从脚本中删除：

- 会话切换后的内存回收
- 会话删除后的稳定常驻值
- 模型选择持久化
- 文件跳转
- 图片输入
- Skill、Subagent、Workflow
- MCP、LSP、ACP 的完整可用性
- 任务最终成功闭环
